# การทดสอบย้อนหลัง 7 วัน — น้ำท่วมสัมมากร (T0 ≈ 26 ก.ย. 2569 04:00 น.) — ข้อมูลจริงทั้งหมด ไม่มีการจำลอง

**คำสั่งฟาวน์เดอร์ (คำต่อคำ)**: "ทดสอบข้อมูลจริงไม่จำลอง ทดสอบใหม่"

**สถานะไฟล์นี้**: **ข้อมูลจริงทั้งหมด ไม่มีการจำลอง** — ทุกค่าในตารางด้านล่างมาจากแหล่งจริงที่ระบุ
URL/ไฟล์ + เวลาที่ระบบรู้ค่านั้นจริง (`run_time`) ไม่มีตัวเลขสมมติ/ตัวแทน/ค่าเฉลี่ยจากสถานการณ์ใดๆ
worker นี้เขียนไฟล์ใหม่เท่านั้น (ไม่แก้/ไม่ commit ไฟล์อื่น, ตาม write-scope ที่ได้รับ). เอกสารคู่กันที่
ไม่ใช่ข้อมูลจริง (ป้าย `[SimulatedData] Simulation=Yes` จากฟาวน์เดอร์) คือ `experiments/2026-09-26-
sammakorn-7day-backtest.md` บน `origin/main` — เอกสารนี้เขียนขึ้นใหม่จากศูนย์ ไม่ใช้ตัวเลขสถานะ/
lead-time ใดๆ จากไฟล์นั้นเป็นฐาน (ใช้เฉพาะเป็นสิ่งที่ต้องเทียบ/หักล้างใน §6).

**Epistemic tag ของไฟล์นี้เอง**: ทุกแถวติดแท็ก VERIFIED/MEASURED/RELAYED/INSTINCT/OPEN ตาม
`AGENTS.md` §2. Ledger ดิบ (24 แถว, append-only) อยู่ที่
`raw/backtests/sammakorn_7day_real_2026-09-27.jsonl` (gitignored, ตามกติกา `raw/`).

**Project decision ที่ได้รับระหว่างงานนี้ (คำต่อคำ)**: "อย่าเชื่อเซนเซอร์มาก ต้องดูความสอดคล้องโดยรวม
ของสมการการไหลด้วย … ตรงคลองแสนแสบเสรีไทยก็มีค่าแปลกๆ ไม่สอดคล้องกับเพื่อนบ้าน" — นำมาใช้ทั้งฉบับ
