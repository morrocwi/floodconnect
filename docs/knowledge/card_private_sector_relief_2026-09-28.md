(cell-on-wheels/COW), จุดชาร์จมือถือที่ศูนย์พักพิง/ร้านค้าปลีก, เครื่องปั่นไฟ/แบตเตอรี่สำรอง/

ไฟฟ้า) — **ไฟดับ → เครือข่ายโทรคมนาคมเสื่อมสภาพ** บันทึกเป็น attribute `power_dependency: true`
บน node สถานีฐาน (ไม่สร้าง edge kind ใหม่)
