## 10 ช่องว่างที่ใหญ่ที่สุด (INSTINCT — จัดลำดับตามผลต่อสัมมากรรอบนี้)

1. **เจ้าของ ST.SPS.01–04 = OPEN** (`AS_SPS_POND`, `AS_SPS01`) — telemetry อยู่บน PumpHistory ของ สนน. แต่ข่าวเก่าเรียกบึงว่าแก้มลิงส่วนตัวหมู่บ้าน;
   ทั้ง 4 สถานี "ขัดข้อง" pumps_on 0 จาก 11 เครื่อง (VERIFIED [FC]) และแถลง กทม. "สาเหตุที่สถานีของหมู่บ้านยังไม่ทราบ" (RELAYED [FC])
2. **ไฟเข้าสถานีสูบ + ไฟสำรอง** (`AS_GRID`, `AS_GEN_BACKUP`, `DC_BACKUP_POWER` ผู้สั่ง 3 ราย ทุกเส้น OPEN) — ไม่มีโหนดใดวัดไฟเข้าสถานี
3. **สถานะบานประตูมีอยู่ใน SCADA แต่ไม่ถึงคน** (`DT_SCADA_GATE` อยู่ในรายการ G2) — repo ต้องอนุมานเองจากส่วนต่างระดับน้ำ
4. **`DC_GATE_MINBURI` ผู้สั่ง 3 ราย** (สนน. / ผู้ว่าฯ กทม. / นายกฯ ตามแบบอย่างปี 2554) และปิดอยู่ (อนุมาน) โดยภาระตกฝั่งสัมมากร
5. **ปตร.ประเวศ-ลาดกระบัง อยู่บนรอยต่อ สนน./กรมชลฯ** — ทั้งความเป็นเจ้าของและผู้สั่งเป็น OPEN; อนุมานว่าปิด ทางใต้ของบึงหมู่บ้านจึงถูกปิดด้วย
6. **คลองบ้านม้า/วังใหญ่/ท่อลอดรามคำแหง ไม่มีเจ้าของที่ยืนยันและไม่มีเครื่องวัด** (อยู่ทั้งใน G1 และ G4)
7. **บึงหมู่บ้านไม่มีเครื่องวัดระดับจริง** — ค่า 0.0 จาก PumpHistory เป็นค่าตอนสถานีขัดข้อง ไม่ใช่ระดับน้ำ
8. **ทะเบียนผู้ป่วยติดเตียงมีผู้อ้างถือ 5 ฝ่าย แต่ทุกเส้น OPEN และไม่ถึงช่องทางใด** (`DT_BEDRIDDEN` ใน G1+G2); `DC_BEDRIDDEN` ผู้สั่ง 3 ราย
9. **ไม่มีระดับเตือนของหมู่บ้าน และไม่มีไซเรน/เสียงตามสาย** (`CH_SIREN` OPEN) ขณะที่ `DC_ALERT` มีผู้ออกคำเตือน 4 ระบบ
10. **ข้อมูลความเสียหาย/คำร้องไม่ย้อนถึงประชาชน** (`DT_DAMAGE`, `DT_TICKETS` ใน G2) และ `DC_DECLARE` ยังเป็น null ใน [FC] — ฐานของการเยียวยายังไม่เกิด
