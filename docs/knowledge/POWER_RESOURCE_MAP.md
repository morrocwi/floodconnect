# ผังอำนาจและทรัพยากรการจัดการน้ำท่วม: จากรัฐธรรมนูญถึงประชาชน

**คำถามตั้งต้น (founder)**: ผู้รับผิดชอบตามรัฐธรรมนูญ และหน่วยงานอื่นที่เกี่ยวข้องทั้งโดยตรงและโดยอ้อมในการจัดการน้ำจนถึงประชาชน
มีใครบ้าง หน่วยงานไหนควบคุมพื้นที่และเครื่องมืออะไร.

(ไม่มีเทศบาล; กทม. เป็นทั้ง อปท. และ "จังหวัด"). การยกผังรังสิตมาใช้กับ กทม. จึงเป็นการเทียบเคียง (INSTINCT) ไม่ใช่การยืนยัน.

## (1) ฐานกฎหมาย

### 1.1 จากบทความรังสิต (RELAYED) — ทั้งหมดที่บทความอ้าง

บทความ **ไม่อ้างรัฐธรรมนูญ และไม่ระบุเลขมาตรา** ใด ๆ. ที่อ้างมีเพียง:
- พ.ร.บ.กำหนดแผนและขั้นตอนการกระจายอำนาจให้แก่องค์กรปกครองส่วนท้องถิ่น พ.ศ. 2542 — อปท. มีหน้าที่ป้องกันและบรรเทาสาธารณภัยในพื้นที่ (RELAYED รังสิต, หน้า 210)
- พ.ร.บ.ป้องกันและบรรเทาสาธารณภัย พ.ศ. 2550 — ผู้บริหารท้องถิ่นเป็น**ผู้อำนวยการท้องถิ่น** มีหน้าที่ช่วยเหลือสนับสนุนหน่วยงานอื่น (RELAYED รังสิต, หน้า 210)
- มติคณะรัฐมนตรี ปี 2552 — อปท. ต้องทำแผน 4 ชุด (ป้องกัน/เตรียมพร้อม/ฉุกเฉิน/หลังเกิดภัย) (RELAYED รังสิต, หน้า 210–211)
- แผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติ พ.ศ. 2553–2557 (RELAYED รังสิต, หน้า 214, 227)
- กฎกระทรวงว่าด้วยผังเมือง, ข้อบัญญัติงบประมาณท้องถิ่น, แผนพัฒนาสามปี (เอกสารวิจัย) (RELAYED รังสิต, หน้า 215)

### 1.2 ส่วนที่บทความไม่ครอบคลุม (RELAYED-GENERAL — ต้องตรวจทุกข้อ)

**รัฐธรรมนูญแห่งราชอาณาจักรไทย พ.ศ. 2560**
- หมวด 14 การปกครองส่วนท้องถิ่น (ราว ม.249–254): ม.250 — อปท. มีหน้าที่และอำนาจดูแลและจัดทำบริการสาธารณะเพื่อประโยชน์ของประชาชนในท้องถิ่น; รัฐต้องจัดสรรรายได้/กระจายอำนาจตามกฎหมาย (RELAYED-GENERAL)
- ม.57 (หน้าที่ของรัฐ) — อนุรักษ์ คุ้มครอง บำรุงรักษา ฟื้นฟู บริหารจัดการ ใช้ประโยชน์ทรัพยากรธรรมชาติ สิ่งแวดล้อม อย่างสมดุลและยั่งยืน โดยให้ประชาชนและชุมชนมีส่วนร่วม (RELAYED-GENERAL)
- ม.58 — การดำเนินการของรัฐที่อาจกระทบคุณภาพสิ่งแวดล้อมต้องศึกษาผลกระทบและรับฟังความเห็นประชาชน (RELAYED-GENERAL)
- ม.43 — สิทธิของบุคคลและชุมชนในการร่วมจัดการทรัพยากรธรรมชาติ/สิ่งแวดล้อม; ม.41 — สิทธิได้รับทราบข้อมูลข่าวสารสาธารณะ (RELAYED-GENERAL)
- มาตราที่ว่าด้วย "ภัยพิบัติ" โดยตรง: **OPEN** — ผู้เขียนผังจำไม่ได้แน่ว่ามีมาตราเฉพาะ; อย่าอ้างจนกว่าจะตรวจตัวบท

**พ.ร.บ.ป้องกันและบรรเทาสาธารณภัย พ.ศ. 2550 (สายบัญชาการ)** (RELAYED-GENERAL; เลขมาตราตามความจำ ต้องตรวจ — และตรวจว่ามีฉบับแก้ไขหลังปี 2550 หรือไม่)
```
คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติ (กปภ.ช.) — จัดทำแผนแห่งชาติ (ประธาน: นายกฯ หรือรองนายกฯ ที่ได้รับมอบหมาย)
  └─ ผู้บัญชาการ = รัฐมนตรีว่าการกระทรวงมหาดไทย  (สาธารณภัยร้ายแรงอย่างยิ่ง: นายกรัฐมนตรีสั่งการได้เอง)
       └─ ผู้อำนวยการกลาง = อธิบดีกรมป้องกันและบรรเทาสาธารณภัย (ปภ. = หน่วยงานกลาง)
            ├─ ผู้อำนวยการจังหวัด = ผู้ว่าราชการจังหวัด
            │    └─ ผู้อำนวยการอำเภอ = นายอำเภอ
            │         └─ ผู้อำนวยการท้องถิ่น = นายก อปท. (นายกเทศมนตรี / นายก อบต.)  ← จุดที่บทความรังสิตยืนยัน (หน้า 210, 221)
            └─ ผู้อำนวยการกรุงเทพมหานคร = ผู้ว่าราชการกรุงเทพมหานคร
                 └─ ผู้อำนวยการเขต / ผู้ช่วยผู้อำนวยการ กทม. = ผู้อำนวยการเขต (เช่น เขตสะพานสูง)
```
- อปพร. (อาสาสมัครป้องกันภัยฝ่ายพลเรือน) ตั้งภายใต้กฎหมายนี้ ขึ้นกับผู้อำนวยการท้องถิ่น/กทม. — บทความรังสิตยืนยันว่า อปพร. ถูกใช้จริง (RELAYED รังสิต, หน้า 220)
- ผู้อำนวยการแต่ละระดับมีอำนาจสั่งอพยพ, ห้ามเข้าพื้นที่, ใช้อาคาร/ยานพาหนะ/เครื่องมือ, เรียกเจ้าหน้าที่ของรัฐในพื้นที่ช่วย (RELAYED-GENERAL)

**การประกาศเขตภัยพิบัติ / เยียวยา** (RELAYED-GENERAL): ระเบียบกระทรวงการคลังว่าด้วยเงินทดรองราชการเพื่อช่วยเหลือผู้ประสบภัยพิบัติกรณีฉุกเฉิน
(ฉบับปี 2562 ตามความจำ — ต้องตรวจ) — ผู้ว่าราชการจังหวัด (ใน กทม. = ผู้ว่าฯ กทม.) ประกาศ "เขตการให้ความช่วยเหลือผู้ประสบภัยพิบัติกรณีฉุกเฉิน" เพื่อเปิดใช้เงินทดรองราชการ; อัตราช่วยเหลือกำหนดโดยหลักเกณฑ์ของกระทรวงการคลัง.

**พ.ร.บ.ทรัพยากรน้ำ พ.ศ. 2561** (RELAYED-GENERAL): คณะกรรมการทรัพยากรน้ำแห่งชาติ (กนช.) มีนายกรัฐมนตรีเป็นประธาน;
สำนักงานทรัพยากรน้ำแห่งชาติ (สทนช.) เป็นหน่วยงานกลาง/ฝ่ายเลขานุการ; **คณะกรรมการลุ่มน้ำ** รายลุ่มน้ำ (22 ลุ่มน้ำ ตามความจำ) จัดทำแผนแม่บทลุ่มน้ำ
และแผนป้องกันน้ำท่วม/ภาวะน้ำแล้ง; องค์กรผู้ใช้น้ำ. สทนช. มีบทบาทประสาน/บูรณาการ **ไม่ได้เป็นผู้เปิด-ปิดประตูหรือเดินเครื่องสูบเอง**.

**พ.ร.บ.การชลประทานหลวง พ.ศ. 2485 (แก้ไขล่าสุดราวปี 2560)** (RELAYED-GENERAL): กรมชลประทานมีอำนาจเหนือ "ทางน้ำชลประทาน" และอาคารชลประทาน
(ประตูระบายน้ำ, ทำนบ, สถานีสูบ) ที่กรมสร้าง/ประกาศ; การปิดกั้น/ดัดแปลงทางน้ำชลประทานต้องได้รับอนุญาต.

**พ.ร.บ.ระเบียบบริหารราชการกรุงเทพมหานคร พ.ศ. 2528** (RELAYED-GENERAL): กทม. มีหน้าที่ (ราว ม.89) รวมถึงการระบายน้ำ, การป้องกันและบรรเทาสาธารณภัย,
การดูแลรักษาที่สาธารณะ, การจัดการทางบก ทางน้ำ ในเขต กทม.; ผู้ว่าฯ กทม. มาจากการเลือกตั้ง; สำนักงานเขตเป็นหน่วยงานของ กทม.

**อื่น ๆ ที่เกี่ยวข้อง (RELAYED-GENERAL)**
- พ.ร.บ.เทศบาล พ.ศ. 2496 — หน้าที่เทศบาลตามชั้น (ตำบล/เมือง/นคร) รวมทางบก ทางน้ำ ทางระบายน้ำ (เลขมาตราต้องตรวจ; บทความรังสิตไม่ได้อ้าง)
- พ.ร.บ.กำหนดแผนฯ กระจายอำนาจ 2542 — ม.16 (เทศบาล/อบต./เมืองพัทยา), ม.17 (อบจ.), ม.18 (กทม.) มีอนุมาตราเรื่องการป้องกันและบรรเทาสาธารณภัย (เลขอนุมาตราต้องตรวจ)
- พ.ร.บ.การจัดสรรที่ดิน พ.ศ. 2543 — สาธารณูปโภคในหมู่บ้านจัดสรร (ถนน ท่อระบาย บ่อหน่วงน้ำ) โอนให้**นิติบุคคลหมู่บ้านจัดสรร**ดูแลได้ ← เกี่ยวกับบึง/ปั๊มในหมู่บ้าน
- พ.ร.บ.การเดินเรือในน่านน้ำไทย พ.ศ. 2456 — กรมเจ้าท่า: ใบอนุญาตสิ่งล่วงล้ำลำน้ำ, การสัญจรทางน้ำ
- พ.ร.บ.การไฟฟ้านครหลวง พ.ศ. 2501 — กฟน. จ่ายไฟใน กทม./นนทบุรี/สมุทรปราการ
- กฎหมายจัดระเบียบราชการกระทรวงกลาโหม — กองทัพมีภารกิจช่วยเหลือประชาชน/บรรเทาสาธารณภัย เมื่อได้รับการร้องขอ/สั่งการ
