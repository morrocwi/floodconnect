- **กฎหมายจัดตั้ง/หลัก**: พระราชบัญญัติทรัพยากรน้ำ พ.ศ. 2561 (VERIFIED, อ้างถึงในหน้ายุทธศาสตร์)
- **fetch status**: OK (200) — https://www.onwr.go.th/ , https://www.onwr.go.th/?page_id=3740 (วิสัยทัศน์/พันธกิจ/ยุทธศาสตร์), https://www.onwr.go.th/?page_id=4150 (โครงสร้างองค์กร) — ดึงเมื่อ 2026-09-27

## พันธกิจ (VERIFIED)
วิสัยทัศน์ (คำต่อคำจากเว็บ, URL: https://www.onwr.go.th/?page_id=3740, ดึง 2026-09-27):
> "เป็นองค์กรชั้นนำในอาเซียนด้านการบริหารทรัพยากรน้ำอย่างบูรณาการบนหลักธรรมาภิบาลภายในปี 2570"

พันธกิจ (คำต่อคำ, URL เดียวกัน):
> "กำหนดนโยบายในการบริหารจัดการทรัพยากรน้ำทั้งประเทศอย่างเป็นระบบ"
> "กลั่นกรองแผนงานและโครงการด้านทรัพยากรน้ำให้สอดคล้องกับยุทธศาสตร์ชาติ"
> "กำกับ ติดตาม ประเมินผลการบริหารจัดการทรัพยากรน้ำของประเทศ"
> "ส่งเสริมการบูรณาการและการมีส่วนร่วมการจัดการทรัพยากรน้ำบนหลักธรรมาภิบาล"

## อำนาจหน้าที่ตามกฎหมาย
VERIFIED (จากหน้าเว็บทางการ): เป็นหน่วยงานกำหนดนโยบาย กลั่นกรองแผนงาน กำกับ/ติดตาม/ประเมินผลการบริหารจัดการน้ำทั้งประเทศ — ตำแหน่ง "ผู้ประสานงานกลาง" (coordinator) เหนือหน่วยปฏิบัติ (รวมทรัพยากรน้ำ กรมชลประทาน กรมทรัพยากรน้ำ ฯลฯ) ไม่ใช่ผู้ควบคุมทรัพย์สินโดยตรง

## โครงสร้างหน่วยย่อยที่เกี่ยวกับน้ำท่วม (VERIFIED, จาก page_id=4150)
สำนักงานทรัพยากรน้ำแห่งชาติ ภาค 1-4 · สำนักงานเลขาธิการ · สำนักงานเลขานุการ กนช. (คณะกรรมการทรัพยากรน้ำแห่งชาติ) · กองนโยบายและแผนแม่บท · กองวิเคราะห์โครงการและงบประมาณ · กองบริหารจัดการลุ่มน้ำ · **ศูนย์อำนวยการน้ำแห่งชาติ** (ศูนย์บัญชาการภาวะน้ำท่วม/แล้งระดับชาติ) · กลุ่มเทคโนโลยีสารสนเทศและการสื่อสาร · กองการต่างประเทศ · กองกฎหมาย

คกก.ทรัพยากรน้ำแห่งชาติ (กนช.) เป็นกลไกนโยบายสูงสุดที่ สทนช. เป็นฝ่ายเลขานุการ — คณะกรรมการลุ่มน้ำ (basin_committee) อยู่ใต้โครงสร้างนี้เช่นกัน

## ทรัพย์สิน/พื้นที่ที่ควบคุม
สทนช. ไม่ได้เป็นเจ้าของโครงสร้างพื้นฐาน (เขื่อน/คลอง/ประตู) โดยตรง — ทำหน้าที่กำกับนโยบายเหนือหน่วยงานปฏิบัติ (RELAYED-GENERAL, ไม่พบตัวเลขทรัพย์สินบนหน้าที่ดึงมา)

## เครื่องมือข้อมูล
- หน้า "สถานการณ์น้ำ" บนเว็บหลัก (พบใน nav, ยังไม่ได้ตรวจ URL ย่อยของ dashboard — OPEN)
- ศูนย์อำนวยการน้ำแห่งชาติ ตามชื่อหน่วยงานควรมี war-room/dashboard กลาง แต่ไม่พบ URL ที่ยืนยันได้ในการดึงรอบนี้ — OPEN

## กระบวนการ (เท่าที่หน้าเว็บระบุ)
สทนช. กำหนดนโยบาย → กนช. (มีนายกฯ เป็นประธานตามโครงสร้างราชการ, ไม่ได้ยืนยันจากหน้าเว็บรอบนี้ — OPEN) อนุมัติ → หน่วยปฏิบัติ (ชลประทาน, กฟผ., ทรัพยากรน้ำ ฯลฯ) ดำเนินการ → สทนช. กำกับ/ติดตาม/ประเมินผล. รายละเอียดขั้นตอนการสั่งเปิด-ปิดประตู/ระบายน้ำเขื่อนจริง ไม่พบในหน้าที่ดึงมา — OPEN

## ช่องทางถึงประชาชน
ไม่พบข้อมูลสายด่วน/ช่องทางร้องเรียนเฉพาะในหน้าที่ดึงมารอบนี้ — OPEN

## สิ่งที่ FloodConnect ใช้ได้ทันที
ยังไม่พบ URL API/dashboard ของ สทนช. เองที่ระบุชัดในหน้าที่ดึงมา — เทียบกับ `sources/registry.yaml` ปัจจุบันไม่มีฟีดจาก onwr.go.th โดยตรง (มีจาก thaiwater.net ของ สสน. ซึ่งเป็นคนละหน่วยงาน) → ต้องสำรวจหน้า "สถานการณ์น้ำ" เพิ่มเพื่อหา dashboard/API จริง

## ตำแหน่งสินทรัพย์ที่ดึงได้ (lat/lon)
OPEN — ไม่พบพิกัดใดๆ ในหน้าที่ดึงมา (สทนช. เป็นหน่วยนโยบาย ไม่ใช่เจ้าของทรัพย์สินกายภาพ จึงไม่คาดว่าจะมี field พิกัดของตัวเอง — ควรดูพิกัดจากหน่วยปฏิบัติ เช่น กรมชลประทาน/กฟผ. แทน)

## OPEN questions
- URL ของ dashboard "สถานการณ์น้ำ" / ศูนย์อำนวยการน้ำแห่งชาติ คืออะไร มี API หรือไม่
- ขั้นตอนการตัดสินใจสั่งเปิด/ปิดประตูระบายน้ำ/ปล่อยน้ำเขื่อนจริง ใครเป็นผู้ลงนามขั้นสุดท้าย (สทนช. เป็นผู้กำหนดนโยบาย แต่ผู้สั่งปฏิบัติจริงคือหน่วยงานเจ้าของทรัพย์สิน — ต้องตรวจสอบ)
- โครงสร้างคณะกรรมการลุ่มน้ำเจ้าพระยา/บางปะกงเฉพาะ (สมาชิก, การประชุม) — ดูการ์ด `basin_committee.md`
