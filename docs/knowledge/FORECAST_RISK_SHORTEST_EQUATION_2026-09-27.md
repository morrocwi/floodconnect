## 2. Delta ที่เหลือจริง ๆ (สิ่งที่ PROP-FLOOD-08-DRAFT ขอเพิ่ม — เท่านั้น)

1. **`C_H` กรณี (e) DESIGN_DECLARED**: เมื่อหน่วย U ไม่มีปั๊ม/ทางออกที่รู้ความจุ แต่มี "ความจุออกแบบ
   ระบบระบายน้ำ" เป็นความลึกฝน/วัน ที่หน่วยงานเจ้าของประกาศ (กทม.: 80 มม./วัน VERIFIED p63) ให้ประกาศ
   `C_H := (H/24)·D_design·A_U` ได้ **โดยต้องพิมพ์ `terms_present := {DESIGN}` และแท็กแหล่ง** — ทำให้ S_H
   ยุบเป็น `L_H = c_U·P_H/((H/24)·D_design)` ไม่ต้องรู้ A_U; c_U ประกาศ = 1 (ขอบบน) เว้นแต่วัดได้
2. **`T_rec(U) := V_stored / Q_out`** (เวลาฟื้นตัวเมื่อฝนหยุด) — ผลปิดรูปของ 03 เมื่อ P = Q_in = 0 และ
   Q_out คงที่; **REFUSED** เมื่อ V_stored ไม่ได้ประกาศ/ไม่ VERIFIED-หรือ-official, หรือ Q_out = 0 (ปั๊ม
   ไม่วิ่ง → ไม่นิยาม ไม่ใช่ "∞"); Q_out ที่ใช้ต้องบอกว่า rated หรือ effective (Q_eff < Q_rated OPEN)
3. **ตัวเศษพจน์ส่วนเกินเก็บกัก `E_k := max(0, S_k − S_safe)`** (จาก "หนี้น้ำ" §7) — positive part ของ
   δ_R ระหว่างสถานะ 03 กับเกณฑ์ประกาศ; รูปแบบเดียวกับ `R_H = Σ max(0, Q_cap − Q_now)` ของ 06 แต่กลับด้าน
   และอยู่บนสถานะเก็บกัก ไม่ใช่อัตราไหล — 06 ไม่มีสถานะเก็บกัก, 03 มี → ต้องตั้งชื่อ

ทุกอย่างอื่น = อ้างรหัสเดิม ไม่เขียนซ้ำ

## 12. สรุปศัพท์ (ตารางเต็มอยู่ที่ `sources/terminology_crosswalk.yaml`, 20 แถว)

- **ตัวเดียวที่ใช้บนหน้าเว็บ/API**: *utilisation ratio (load-to-capacity)* = `L_H` · *level of service* = `D_design` (80 มม./วัน) ·
  *drawdown time* = `T_dd` · *storage exceedance* = `E_k` (ป้ายสาธารณะ "หนี้น้ำ") · *lead time* + `warning_scope`
- **คำที่ห้ามสลับ**: "storage deficit" (สากล = ที่ว่างเหลือ) ≠ `E_k` (ส่วนเกิน); rated ≠ effective capacity; conveyance ≠ pumping ≠ outfall
  capacity (ใช้ตัวที่น้อยสุด ไม่รวม); regional-class lead ≠ node achieved lead
- แต่ละแถวมี: `standard_en` + variants, `thai_official` (อ้างไฟล์ในคลัง), `toledo_symbol`, `si_unit` (จาก `units_datum_crosswalk.yaml`),
  `supplier` (API field / เกจ), `reference_standard` **ระบุชื่อเท่านั้น** (WMO-No.1072, WMO-No.168, Chow–Maidment–Mays *Applied Hydrology*,
  EPA SWMM manual, USACE HEC-HMS/RAS, UK EA, ISO 14090/14091 — **ไม่ได้เปิดอ่านคืนนี้**), `tag` (VERIFIED = คำนี้มีในเอกสารเราแล้ว;
  RELAYED = ยังไม่มี), `public_th_candidate` (INSTINCT จนกว่าผู้ก่อตั้งอนุมัติถ้อยคำ)
- OPEN: การแมป flag คุณภาพข้อมูลของเรา (SUSPECT/STALE/…) กับรหัสของ WMO — ยังไม่เปิดเอกสาร WMO จึงไม่ระบุรหัส
