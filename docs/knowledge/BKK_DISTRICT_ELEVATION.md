# ระดับความสูงพื้นดินรายเขต กรุงเทพมหานคร (เทียบ MSL) — สถานะปัจจุบัน

**สถานะรวม**: MEASURED-on-map (สุ่มอ่านจากแผนที่จริงในคลัง) + OPEN (ครึ่งหนึ่งของเขตอ่านค่าไม่ได้อย่างมั่นใจ)
**บันทึกเข้า**: 2026-09-27 · **ข้อมูลดิบ**: `sources/bkk_district_elevation.yaml`

## จุดเริ่ม: คำสั่ง founder ไม่ตรงกับเนื้อหาบทความที่ชี้มา

Founder ชี้ไปที่ https://policywatch.thaipbs.or.th/article/environment-190 ให้ใช้เป็นแหล่งเรื่องการทรุดตัว
ของแผ่นดิน/พื้นที่ต่ำกว่าระดับน้ำทะเล — **ตรวจแล้ว บทความนี้ไม่มีเนื้อหาด้านนี้เลย** (เป็นบทความเรื่องระบบ
"จราจรน้ำ"/ผลงานสำนักการระบายน้ำ กทม. วาระผู้ว่าฯ ชัชชาติ) รายละเอียดเต็มอยู่ที่
`docs/knowledge/card_media_thaipbs_policywatch_env190.md` — ข้อมูลในไฟล์นี้ทั้งหมดจึงมาจากแหล่งอื่น ไม่ใช่
จากบทความที่ founder ชี้มา (ระบุตรงนี้เพื่อไม่ให้เข้าใจผิดว่าเป็นการสกัดจากบทความนั้น)

## วิธี (method)

1. หาจุดศูนย์กลาง (centroid) พิกัด lat/lon ของ 50 เขต จาก Wikipedia "List of districts of Bangkok"
   (ใช้เป็น**ตัวชี้จุดสุ่ม**เท่านั้น ไม่ใช่แหล่งความสูง)
2. แปลง WGS84 → UTM Zone 47N (EPSG:32647) → พิกัดพิกเซลบนภาพ `raw/rtsd_2010/flood_01.png` โดยใช้สมการ
   affine ที่ georeference ไว้แล้วใน `raw/rtsd_2010/georef.json` (สมการเดียวกับที่ใช้สุ่มจุดสัมมากรใน
   `sammakorn_sample.json`)
3. อ่านสี RGB รอบจุดนั้นเป็นบล็อก 5×5 พิกเซล (~165×165 ม. บนพื้นดินจริง) จับคู่กับตารางสีตำนาน (legend) 9 ชั้น
   ของแผนที่ (< 0 ม., 0-0.5, 0.5-1, ..., ≥3.5 ม.) แล้วนับเสียงข้างมาก (majority vote)
4. **ตัวกรองคุณภาพ**: ถ้าบล็อก 5×5 มีพิกเซล ≥4/25 อยู่ในชั้นที่ห่างจากชั้นข้างมาก ≥2 ชั้น (≥1 ม.) — สัญญาณว่า
   จุดสุ่มไปโดนตัวอักษรชื่อเขต/เส้นถนน/จุดคันกั้นน้ำสีแดงบนแผนที่ (ปัญหาเดียวกับที่บันทึกไว้แล้วใน
   `sammakorn_sample.json` §limits) — เขตนั้นถูกทิ้งเป็น **OPEN** แทนที่จะรายงานค่าที่ปนเปื้อน

**ข้อจำกัดสำคัญ**: นี่คือการสุ่ม**จุดเดียว**ต่อเขต (จุดศูนย์กลางที่ Wikipedia ระบุ) ไม่ใช่สถิติของทั้งพื้นที่เขต —
เขตหนึ่งอาจมีทั้งพื้นที่สูงและต่ำปนกัน ตัวเลขในตารางนี้คือ "ค่าที่จุดนั้นจุดเดียวอ่านได้" ไม่ใช่ค่าเฉลี่ย/ค่ากลาง
ของทั้งเขต และแผนที่ RTSD สำรวจ ต.ค. 2553 — การทรุดตัวของแผ่นดินตั้งแต่นั้นอาจทำให้ระดับปัจจุบันต่ำกว่าที่แผนที่
ระบุ (caveat เดียวกับที่มีอยู่แล้วใน `sammakorn_sample.json`)

**หมายเหตุ 50/50**: ครึ่งหนึ่งพอดี (25/25) ของเขตทั้งหมดอ่านค่าไม่ได้อย่างมั่นใจในรอบสุ่มนี้ — สะท้อนข้อจำกัดของ
วิธีสุ่มจุดเดียวที่จุดศูนย์กลางเขต (ซึ่งมักเป็นจุดที่แผนที่พิมพ์ชื่อเขตทับอยู่พอดี) มากกว่าจะสะท้อนว่าครึ่งเมือง
ไม่มีข้อมูลจริง — ถ้าจะแก้ ต้องขยับจุดสุ่มออกจากตำแหน่งป้ายชื่อ หรือสุ่มหลายจุดในขอบเขตเขต (ต้องมีขอบเขต polygon
ของแต่ละเขต ซึ่งคลังนี้ยังไม่มี) — ไม่ทำในรอบนี้ (เกินงบเวลา 20 นาทีที่กำหนดไว้สำหรับการสุ่มของ task นี้)

## ความขัดแย้งระหว่างแหล่ง

ไม่มี — เพราะบทความ thaipbs ที่ founder ชี้มาไม่มีตัวเลขด้านนี้เลย (ดู card ด้านบน) จึงไม่มีตัวเลขที่สองให้เทียบ
กับค่าที่อ่านจากแผนที่ RTSD ในไฟล์นี้ นี่คือ**ช่องว่างแหล่งข้อมูล** ไม่ใช่ความขัดแย้ง — ยังไม่มีเอกสารทางการ
(กรมทรัพยากรธรณี/GISTDA/จุฬาฯ) เรื่องอัตราการทรุดตัวรายเขตในคลังนี้เลย (`subsidence_rate_mm_yr` เป็น null
ทุกแถวใน YAML)

## สำหรับผู้สร้าง KG (build_river_kg.py) — ข้อเสนอ ไม่ได้แก้ไฟล์จริง

**ไม่ได้แก้ `build_river_kg.py` หรือ `water_system_dag.mmd` ในงานนี้** — บันทึกไว้เป็นข้อเสนอสำหรับรอบถัดไป:

- เพิ่ม node class ใหม่ `district` แยกจาก `AG_DIST_*` ที่มีอยู่แล้ว (ซึ่งหมายถึง**สำนักงานเขต**/หน่วยงาน ไม่ใช่
  พื้นที่ทางภูมิศาสตร์) — ปัจจุบัน `water_system_dag.mmd` มีเพียง `AG_DIST_SS` (สำนักงานเขตสะพานสูง) เป็น district
  node เดียว ยังไม่มี node ภูมิศาสตร์คู่กัน
- เสนอ 50 node ใหม่ (หนึ่งต่อเขต) เก็บ attribute: `ground_level_m_msl_min/max/typical`, `below_msl`,
  `elevation_tag` — ดึงจาก `sources/bkk_district_elevation.yaml` โดยตรง (ไม่ hardcode ในกราฟ)
- เชื่อม edge `AG_DIST_SS -->|"GOVERNS:V"| DIST_GEO_SAPHANSUNG` (ตัวอย่าง) เพื่อแยกอำนาจปกครอง (agency)
  ออกจากพื้นที่ภูมิศาสตร์ (geography) อย่างชัดเจน แทนการรวมสองอย่างไว้ใน node เดียวเหมือนปัจจุบัน
- เหตุผลที่ควรแยก: `AG_DIST_SS` มีไว้แทนอำนาจสั่งการ/CMD edges (เช่น สั่งอพยพ) ส่วน node ภูมิศาสตร์ใหม่มีไว้แทน
  "ความเสี่ยงจากตำแหน่ง" (below MSL, ระดับพื้นดิน) ซึ่งเป็นคนละมิติกัน — ผสมกันจะทำให้ query อำนาจ (bottleneck
  analysis ที่มีอยู่แล้วใน `tools/dag/bottlenecks.py`) กับ query ความเสี่ยงภูมิศาสตร์ปนกันโดยไม่จำเป็น
