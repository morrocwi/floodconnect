ระดับรวม:
- **สูงสุด** ⇔ น้ำเหนือ = 2 **และ** น้ำหนุน = 2 **และ** การระบาย = 2
- **สูง** ⇔ มีอย่างน้อย 2 ตัวขับที่ = 2
- **ปานกลาง** ⇔ มี ≥1 ตัวที่ = 2 หรือ ≥2 ตัวที่ ≥1
- **ต่ำ** ⇔ นอกนั้น

การจัดการค่า R: คำนวณสองรอบ รอบหนึ่งให้ R = 2 (กรณีเลวร้าย) อีกรอบให้ R = ค่าต่ำสุดที่จองไว้ (กรณีเบาสุด) และรายงานกรณีเลวร้ายก่อน

ทุกเงื่อนไขเป็นแบบ "ปิดด้านบน" คือถ้าตัวขับใดสูงขึ้น ระดับรวมจะไม่ลดลง (**monotone**; ตรวจครบทั้ง 81 กรณีใน `test_combined_class_is_monotone_in_every_driver`)
**ไม่มีการสร้างดัชนีตัวเลข**: ไม่มีการบวก ถ่วงน้ำหนัก หรือเฉลี่ย

ป้ายรายวัน:
- ก่อนถึงวันแรกที่ "สูงสุด" = **เพิ่มขึ้น**
- วัน "สูงสุด" = **สูงสุด**
- หลังจากนั้น = **ลดลง** ยกเว้นระดับกลับขึ้นอีก
- ระดับ "ต่ำ" = **ต่ำ**

**ข้อจำกัดของกติกา (บอกตรง ๆ)**:
- ฝนไม่มีผลต่อระดับรวม "สูงสุด" เพราะกติกานี้วัดระดับแม่น้ำ ฝนไปเข้าตารางของพื้นที่ปิดล้อมแทน
- ระดับการระบายหลัง 28 ก.ย. ใช้ค่า C.12 แบบ HELD จึงเป็น 2 ตลอดช่วง ตัวที่ทำให้แต่ละวันต่างกันคือน้ำหนุนกับน้ำเหนือ
- ขีด 1.14 ม. และ 1,409 ลบ.ม./วิ เป็นจุดอ้างอิงที่เราเลือกเอง (INSTINCT) ถ้าย้ายขีด 1.14 ลงไปที่ 1.12 วันที่ 30 ก.ย. จะกลายเป็น "สูงสุด" ด้วย
  → ช่วงจะเร็วขึ้นเป็น 30 ก.ย. 09:02 ในกรณีที่เข้มกว่านี้
