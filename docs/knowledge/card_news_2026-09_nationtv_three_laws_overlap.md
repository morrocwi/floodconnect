## (1) หลักการ/ปัญหาเชิงโครงสร้างที่คลิประบุ (RELAYED, เวลาในคลิป)

1. **สามกฎหมายให้อำนาจซ้อนกันในเหตุเดียว** (0:00, 7:09–8:40) — "มันมีตัวพรบ.ป้องกันและบรรเทาสาธารณภัยอยู่แล้ว ... แต่เราไปออกเป็น
   พรก.ฉุกเฉินออกมาทับไปอีกทีนึง"; "มันมีพ.ร.บ.ทรัพยากรน้ำ ... แล้วพ.ร.บ.ตัวนี้เงียบไปเลย ... ให้อำนาจไม่น้อยกว่าพรก.ฉุกเฉิน";
   พ.ร.บ.ทรัพยากรน้ำ (ประกาศปี 61) ให้ "นายกมีอำนาจจัดตั้งศูนย์บัญชา[การ]เฉพาะกิจโดยนายกเป็นผู้บัญชาการเอง" เมื่อเกิดวิกฤตน้ำ
   ทั้งท่วมและแล้ง (มาตราไม่ได้ระบุในคลิป — OPEN)
   หน่วยที่เกี่ยวข้อง: นายกฯ, มหาดไทย, ปภ., กนช./สทนช., สมช.
2. **ผู้บัญชาการกับผู้สั่งผู้บัญชาการเป็นคนเดียวกัน** (2:42–3:40) — "มาตรา 31 ถ้าเกิดสาธารณภัยร้ายแรง ... นายกหรือรองนายกที่รับมอบหมาย
   มีอำนาจไปสั่งการผู้บัญชาการกับผู้อำนวยการ ... ผู้บัญชาการตามกฎหมายฉบับนี้ก็คือรัฐมนตรีว่าการกระทรวงมหาดไทย"; "ตอนนี้ท่านนายก
   ควบมหาดไทยด้วย ... ท่านต้องสั่งตัวเอง" หน่วยที่เกี่ยวข้อง: นายกฯ, รมว.มหาดไทย
3. **สายผู้อำนวยการตาม พ.ร.บ.ป้องกันฯ 2550 และหน้าที่ครบวงจร** (0:00, 3:48–4:45) — ผู้ว่าฯ = ผู้อำนวยการจังหวัด, นายอำเภอ = ผู้อำนวยการ
   อำเภอ; ต้องรับผิดชอบ "ตั้งแต่ก่อนเกิดเหตุ ระหว่างเกิดสาธารณภัย ... การขนย้ายอพยพ ... รวมถึงหลังเกิด ... ฟื้นฟู ... เก็บรวบรวมข้อมูลของ
   ผู้เสียชีวิต ของผู้ได้รับบาดเจ็บ ของผู้ที่ทรัพย์สินหาย" และ "เวลาจะไปร้องกับภาครัฐ ... ก็ต้องไปเอาข้อมูลจากทางราชการ"
   หน่วยที่เกี่ยวข้อง: ผู้ว่าฯ, นายอำเภอ
4. **ตำรวจ/ทหาร/ท้องถิ่นเป็น "ผู้สนับสนุน" นอกสายบัญชาการ** (5:14) — "ผู้กำกับนี่จริงๆแล้วอยู่นอกกลไกของพระราชบัญญัติป้องกันและบรรเทา
   สาธารณภัย ... ตำรวจ ทหาร หรือหน่วยงานอื่นๆ รวมถึงท้องถิ่นเนี่ยจะต้องเป็นผู้สนับสนุน ... ถ้าไม่ให้ความร่วมมือเนี่ยก็จะดำเนินการลงโทษได้"
   หน่วยที่เกี่ยวข้อง: ตำรวจ, ทหาร, อปท.
5. **วอร์รูมทหาร vs ศูนย์ส่วนหน้าฝ่ายการเมือง — "ใครควรต้องสั่งใคร"** (9:07, 10:30) — "ตัวศูนย์ปฏิบัติการที่เป็นวอร์รูมเนี่ยเป็นฝ่ายการเมือง
   เป็นผอ."; "การตั้งกองบัญชาการส่วนหน้ามันซ้อนมั้ย เพราะจริงๆมีวอร์รูมที่ผู้บัญชาการทหารสูงสุดดูแล แต่ก็มี [รองนายกฯ ผอ.ศนภ.] มาอยู่หน้างาน
   อีก ... แล้วใครควรต้องสั่งใคร ... ต้องทำงานฟังใครดี" หน่วยที่เกี่ยวข้อง: กองบัญชาการกองทัพไทย, ศนภ., แม่ทัพภาค
6. **เหตุผลของ พ.ร.ก.ฉุกเฉิน ตาม สมช.** (11:30–13:10) — ลดขั้นตอน; "บูรณาการทุกภาคส่วน ทหาร ตำรวจ ฝ่ายพลเรือน และภาคเอกชน ระดม
   สรรพกำลัง ... รวมถึงงบประมาณ ... ไม่มีขีดจำกัด"; "โอนอำนาจตามกฎหมายของหน่วยงานที่เกี่ยวข้องมาให้นายกคนเดียว"; "เพื่อให้เป็นเอกภาพ
   ในการบูรณาการข้อมูลและการสื่อสารภาครัฐ ให้สื่อสารไปในทางเดียวกัน ... ไม่ได้ต้องการปิดกั้นการสื่อสาร" หน่วยที่เกี่ยวข้อง: สมช., นายกฯ
7. **สื่อสารล่มในพื้นที่ทำให้สายบัญชาการขาด** (1:04–2:08) — กรมการปกครองระบุว่า "ผู้บังคับบัญชาทุกระดับไม่สามารถติดต่อสื่อสารสั่งการได้เลย"
   และไม่เข้าประชุมรายวันกับศูนย์บรรเทาสาธารณภัยมณฑลทหารบกที่ 42; คำชี้แจงอีกฝั่ง: "น้ำมันท่วม 3 เมตร ไฟไม่มี สัญญาณเน็ตไม่มี โทรไม่ได้"
   (สองฝั่งขัดกัน — ไม่ตัดสิน) หน่วยที่เกี่ยวข้อง: กรมการปกครอง, อำเภอ, มณฑลทหารบก
