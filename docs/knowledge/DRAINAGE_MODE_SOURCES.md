## 1. หน่วยงานรัฐพูดว่าอะไรบ้าง (สรุป)

### (a) ระดับนโยบาย/พื้นที่: "ระบบพื้นที่ปิดล้อม" (polder system)

`RELAYED` (สรุปจากผลค้นเว็บ ยังไม่ได้เปิดอ่าน PDF ต้นทางเอง — แผนปฏิบัติราชการประจำปี พ.ศ. 2567
สำนักการระบายน้ำ กทม.): กทม. ใช้ระบบ **"พื้นที่ปิดล้อม"** มาตั้งแต่หลังน้ำท่วมใหญ่ปี 2538 แบ่งเป็น
2 ระบบย่อย — **(1) ป้องกัน** (กันน้ำหลาก/น้ำทะเลหนุนจากแม่น้ำ) และ **(2) บรรเทา** (ระบายน้ำฝนที่ขัง
ในพื้นที่ปิดล้อม) — โดยตัวเลขขีดความสามารถระบบปัจจุบัน (58.7 มม./ชม.) ตรงกับตัวเลข **VERIFIED**
เดิมใน `docs/CAPACITY.md` (คนละปีเอกสาร แต่ตัวเลขตรงกัน — ยืนยันซ้ำโดยบังเอิญ) พื้นที่ปิดล้อม
ฝั่งตะวันออกในแนวคันกั้นน้ำมีขนาด**ประมาณ 650 ตร.กม.** นี่คือคำตอบเชิงแนวคิดที่ตรงกับคำถามฟาวน์เดอร์
ที่สุด: พื้นที่ปิดล้อมคือพื้นที่ที่ **"ไหลเองไม่ได้เสมอ ต้องมีระบบจัดการ (ทั้งแรงโน้มถ่วงเมื่อทำได้ +
ปั๊มเมื่อทำไม่ได้)"** โดยนิยาม ไม่ใช่พื้นที่ที่ไหลเองได้ตลอด

### (b) กลไกทั่วไป (มูลนิธิปิดทองหลังพระ, RELAYED, อ่านมาก่อนงานนี้แล้ว)

`docs/knowledge/card_pidthong_kaemling_royal_initiative.md` อธิบายกลไก 3 ขั้นของแก้มลิง/ปตร.
ฝั่งตะวันออก: **Gravity Flow** (ระบายเมื่อน้ำทะเล < ระดับน้ำในคลอง) → **One Way Flow** (ปิดประตู
กันน้ำย้อนเมื่อน้ำทะเลสูงกว่า) → **สูบเพิ่ม** เมื่อจำเป็น นี่คือคำตอบระดับ "หลักการทั่วไป" ไม่ใช่
คำแถลงทางการต่อประตูใดประตูหนึ่งโดยเฉพาะ

### (c) ข้อมูลเปิด กทม. จริง — พบ "ประตูเปิดลอย" (floating one-way gate), VERIFIED

งานนี้ดึง 2 ชุดข้อมูลเปิดของ กทม. เอง (`data.bangkok.go.th`) มาอ่านตรง ๆ เป็นครั้งแรก:

- `raw/live/bma_open_data_floodgate/2026-09-27T104746Z_floodgate.csv` (332 แถว)
- `raw/live/bma_open_data_pump_station/2026-09-27T104714Z_pump-station.csv` (282 แถว)

คอลัมน์ `water_control` เป็นช่องข้อความอิสระ (free text) หรือระดับควบคุมเป็นตัวเลข แล้วแต่โครงสร้าง
— **8 แถว** (4 ใน floodgate.csv, 4 ใน pump-station.csv) มีข้อความตรงตัวว่า **"ประตูเปิดลอย
น้ำไหลเข้าให้ปิดประตู"** หรือ **"ประตูเปิดลอย"** เฉย ๆ — นี่คือ**คำแถลงทางการ (VERIFIED, อ่านเอง
จากไฟล์ข้อมูลเปิดของ กทม. โดยตรง)** ว่าโครงสร้างเหล่านี้เป็น**ประตูทางเดียวแบบลอยตัว**: เปิดเองด้วย
แรงโน้มถ่วงเพื่อระบายออก แล้วปิดเองเมื่อน้ำจะไหลย้อนเข้า — **ไม่มีปั๊มระบุในทั้ง 8 แถวนี้** จุดที่พบ:
บางชัน(ตอนสวนสยาม)/บึงตาเกตุ (เขตมีนบุรี), ลำปลาทิว/คลองสองลำปลาทิว (เขตหนองจอก), และทำนบกั้นน้ำ
คลองสามวา/สี่ตะวันออก/สามตะวันออก/สองตะวันออก (เขตสามวา) — **ไม่มีจุดใดอยู่บนเส้นทางของสัมมากร**

### (d) RID — ฝั่งตะวันออกตอนล่าง ระบายด้วยปั๊มเท่านั้น (RELAYED)

`โครงการส่งน้ำและบำรุงรักษาพระองค์ไชยานุชิต` และ `ชลหารพิจิตร` (สมุทรปราการ) ถูกอธิบาย (ผลค้นเว็บ,
RELAYED, ยังไม่ได้อ่านเอกสารต้นฉบับ กรมชลประทาน โดยตรง) ว่าใช้ **สถานีสูบน้ำสุวรรณภูมิ** +
**สถานีสูบน้ำริมคลองชายทะเล** สูบน้ำลงทะเลเป็นขั้นสุดท้าย — ไม่มีคำว่า "แรงโน้มถ่วง" ปรากฏสำหรับ
จุดเหล่านี้เลยในแหล่งที่สำรวจ สอดคล้องกับพื้นที่ปิดล้อมส่วนล่างที่อยู่ต่ำกว่าระดับทะเลปกติ

## 3. คำตอบสำหรับสัมมากร (บึงสัมมากร → คลองบ้านม้า 2 → แสนแสบ)

`OPEN` ทั้งสามช่วง — **ไม่มีหน่วยงานใดเคยแถลงโหมดการระบายของเส้นทางนี้เลย** งานนี้ตรวจซ้ำ
(grep ตรงในไฟล์ CSV ที่ดึงมาใหม่ทั้ง 2 ชุด) ไม่พบแถวใดอ้างถึง "สะพานสูง"/"บ้านม้า"/"วังใหญ่"/
"สัมมากร" เลยสักแถว — สอดคล้องกับทุกการสำรวจก่อนหน้าใน repo นี้ (`AGENTS.md` §8,
`FLOODCONNECT_TOPOLOGY.md`, `docs/CAPACITY.md` §2)

**สิ่งที่มีอยู่แล้ว (ไม่ใช่ทางการ, INSTINCT)**: `site/inputs/areas/sammakorn.balance.yaml`
ประกาศเองว่า **"ตัวตัดสินของสัมมากรคือปั๊มบึงเดินหรือไม่"** — คือโมเดลของหมู่บ้านเองถือว่าเส้นทางนี้
เป็น **pump-dependent ในทางปฏิบัติ** (ถ้าปั๊ม ST.SPS ไม่เดิน น้ำในหมู่บ้านไม่ลดแม้ กทม.ระบายหมด
เพราะคลองรอบบ้านยังสูงกว่าพื้น) มีสถานการณ์จำลอง `pump2_gravity` ที่สมมติว่าเมื่อ กทม.ระบาย
คลองรอบนอกจนพร่องแล้ว จะมีแรงโน้มถ่วงช่วยระบายเพิ่มอีก ~1 ลบ.ม./วิ — **แต่ตัวเลขนี้เป็น
สมมติฐานของโมเดล (INSTINCT) ไม่ใช่การวัดหรือคำแถลงทางการ**

**ใครควรถูกถาม**: (1) **นิติบุคคลหมู่บ้านสัมมากร** — เจ้าของปั๊ม ST.SPS.01-04 และบึง/คลองภายใน
หมู่บ้านเอง เป็นแหล่งเดียวที่มีข้อมูลจริง ไม่มีทางลัดจากแหล่งสาธารณะใด ๆ ที่สำรวจแล้ว (2)
**สำนักงานเขตสะพานสูง** — สนน. เขต ที่ควรมีแผนระบายน้ำระดับเขตครอบคลุมเส้นทางนี้ แต่ยังไม่พบ
เอกสารเผยแพร่ (3) **สำนักการระบายน้ำ กทม. (สนน. ส่วนกลาง)** — เจ้าของข้อมูลเปิดทั้ง 2 ชุดที่ใช้
ในงานนี้ ควรเป็นผู้ถูกถามต่อว่าคลองบ้านม้า/วังใหญ่บนมีข้อมูลกลไกหรือไม่ (ยังไม่มีในชุดข้อมูลเปิดที่พบ)

## 4. สิ่งที่ยังเป็น OPEN

- โหมดการระบาย (gravity/pump/mixed) ของ 4 ปตร.หลักฝั่งตะวันออก (SSB.10/09, PWT.03/04) — มีแต่
  ระดับควบคุมเป็นตัวเลข ไม่มีกลไกระบุ
- โหมดการระบายทั้งเส้นทางสัมมากร (บึง → บ้านม้า 2 → แสนแสบ) — ไม่มีคำแถลงทางการเลย
- คู่ bed/control-level ที่พอสำหรับคำนวณ derived_geometry (tier C) — มีตัวอย่างเดียว (WL.SSB.12)
  ไม่มีคู่เทียบ จึงคำนวณไม่ได้ในงานนี้
- เอกสาร RID ต้นฉบับ (ไม่ใช่สรุปจากผลค้นเว็บ) สำหรับพระองค์ไชยานุชิต/ชลหารพิจิตร — ยังไม่ได้เปิดอ่าน
  โดยตรง (RELAYED เท่านั้น)
- เอกสารแผนปฏิบัติราชการ พ.ศ. 2567 (ตัวเต็ม) ที่ระบุ "ระบบพื้นที่ปิดล้อม" — ยังไม่ได้เปิดอ่านตัว PDF
  โดยตรง (RELAYED เท่านั้น)

## 5. การผูกเข้าโครงสร้างเดิม (wiring note)

- **KG node attribute**: เสนอเพิ่ม `drainage_mode` (ค่า: `gravity`/`pump_only`/`tide_gated`/
  `mixed`/`OPEN`) และ `drainage_mode_basis` (`official_statement`/`derived_geometry`/`OPEN`)
  เป็น attribute ของ node ประเภท `asset` (ปตร./สถานีสูบ) และของ `area`/`district` node ใหม่ที่
  เพิ่งเพิ่มใน build 3 (ดู `docs/FLOODCONNECT_TOPOLOGY.md` ชั้น 3) — ไม่ใช่ node แยกต่างหาก
- **PROP-FLOOD-06 (D_H/R_H term selection)**: เมื่อสมการเลือกเทอมการระบาย (D_H สำหรับ discharge
  แบบแรงโน้มถ่วง เทียบ R_H สำหรับการเติมด้วยปั๊ม) drainage_mode ของโครงสร้างที่เกี่ยวข้องควรเป็น
  input ที่บอกว่าเทอมไหนใช้ได้ — โครงสร้างที่ mode=OPEN ควรบังคับ REFUSED ต่อการเลือกเทอมนั้น
  (ตาม Toledo discipline ของ repo นี้ — ห้ามเดาเทอมสมการเมื่อ input พื้นฐานยังไม่ยืนยัน) นี่เป็น
  ข้อเสนอเชิงเอกสารเท่านั้น งานนี้ไม่ได้แก้ `water_balance.py`/สมการใด ๆ
- **Typology edge kinds**: `tide_gated`/`mixed` structures ควรพิจารณาเพิ่ม edge kind ใหม่
  (เช่น `DRAINS_TO_ONEWAY` แยกจาก `DRAINS_TO` ธรรมดา) เพื่อแยกทิศทางที่ "ไหลได้ทางเดียวเท่านั้น"
  ออกจากทิศทางที่ไหลได้ทั้งสองทาง — ข้อเสนอเชิงเอกสาร ยังไม่ได้แก้ `.mmd`/graphml ใด ๆ ในงานนี้
