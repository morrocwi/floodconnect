# คลังคำถามผู้บริหารน้ำ — matrix ตามช่วงเวลา × ระดับปกครอง

**เป้าหมายของไฟล์นี้**: ประกอบเป็นชุดคำถามที่ "ผู้บริหารจัดการน้ำ" ในประเทศไทยต้องตอบได้ ครอบคลุม
ตั้งแต่ระดับชาติ-ลุ่มน้ำ ลงไปถึงหมู่บ้าน-ครัวเรือน แล้วเทียบกับ**สิ่งที่คลังข้อมูล (repo นี้)
มีอยู่จริงตอนนี้** — ไม่ใช่คลังคำตอบ แต่เป็นแผนที่ของช่องว่าง (gap map)

**tag สถานะ** (ตาม epistemic floor ของ workspace): `มีแล้ว(VERIFIED)` / `มีแล้ว(MEASURED)` /
`มีแบบ RELAYED` / `อนุมาน (INSTINCT)` / `ขาด` — ตรวจจากไฟล์จริงในคลังนี้ ณ วันที่ 2026-09-27:
`sources/registry.yaml`, `docs/CAPACITY.md`, `docs/DATA_SYSTEM.md`,
`docs/LESSONS_nodes_2026-09-27.md`, `docs/knowledge/README.md` + card สองใบ, และคีย์ใน
`site/dist/data.json` (`generated_at_bkk, epistemic_note, default_area, forecast,
forecast_caveat_th, all_sources, bangkok_east_water_balance, bma_briefing, capacity_records,
drain_timeline, sammakorn_rough, forecast_7day_compare, canal_graph, burden_ledger, areas`)
และตาราง `data/observations.sqlite` (`observations, documents, method_evaluation,
contradictions, readout_log`).

รหัสคำถาม: `Q-<phase><level>-<n>` โดย phase = `PRE`(ก่อนฤดู) / `72H`(ก่อนเหตุ 72 ชม.) /
`DUR`(ระหว่างเหตุ) / `POST`(หลังเหตุ); level = `NAT`(ชาติ-ลุ่มน้ำ) / `BKK`(กทม.-จังหวัด) /
`DIST`(เขต-อปท.) / `VLG`(หมู่บ้าน-ครัวเรือน)
