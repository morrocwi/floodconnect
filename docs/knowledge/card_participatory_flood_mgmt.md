## (b) คำถาม/วิธีการ (RELAYED)

- วัตถุประสงค์: ศึกษากระบวนการบริหารจัดการทรัพยากรธรรมชาติในพื้นที่แบบมีส่วนร่วมเพื่อรับมือและแก้ไขอุทกภัย (หน้า 317)
- วิธี: สังเคราะห์แนวคิดการบริหาร (4M, องค์ประกอบ Halpin), บันไดการมีส่วนร่วม (หลายสำนัก) และเอกสารกรมทรัพยากรน้ำ แล้วเสนอ "2 แนวทาง" (หน้า 320–329)

## (c) ข้อค้นพบตามมิติ (RELAYED พร้อมหน้า)

### ความรู้ — สาเหตุอุทกภัย
- อุทกภัยเกิดจากน้ำส่วนเกินเกินขีดความสามารถระบายของแม่น้ำลำคลอง + การปิดกั้นการไหลตามธรรมชาติโดยมนุษย์ (หน้า 319) — อ้างกรมทรัพยากรน้ำ 2552
- ธรรมชาติ: มรสุมตะวันตกเฉียงใต้ พายุจากทะเลจีนใต้/แปซิฟิก พายุจากอ่าวเบงกอล น้ำทะเลหนุนในที่ราบลุ่มใกล้ปากอ่าว (หน้า 319)
- มนุษย์: บุกรุกป่าต้นน้ำ เปลี่ยนการใช้ที่ดิน (ป่า→ชุมชน, เกษตร→อุตสาหกรรม/หมู่บ้านจัดสรร) ทำให้พื้นที่รับน้ำตามธรรมชาติ/แก้มลิงไม่พอ (หน้า 319–320)
- **ขีดความสามารถ**: โครงการพัฒนาแหล่งน้ำเก็บกักช่วงน้ำหลากไม่เพียงพอ รับน้ำเกินค่าปกติไม่ได้; "เครื่องมือที่ใช้ในการบริหารจัดการน้ำไม่สามารถใช้การได้ตามต้องการในช่วงเวลาน้ำหลากและไม่เพียงพอ อาทิ ประตูระบายน้ำ อาคารบังคับน้ำ และเครื่องสูบน้ำ" (หน้า 320)
- ชุมชนสร้างบนพื้นที่น้ำท่วมขังเดิม ถนน/สาธารณูปโภครุกล้ำกีดขวางทางน้ำ (หน้า 320)
- ประเภทน้ำท่วม: น้ำท่วมขัง/ล้นตลิ่งจากระบบระบายไม่มีประสิทธิภาพ (มักเกิดท้ายน้ำและเมืองใหญ่) vs น้ำท่วมฉับพลัน/น้ำป่า รวมถึงเขื่อน/อ่างเก็บน้ำพัง (หน้า 320)
- ภาคประชาชนได้รับผลกระทบโดยตรงแต่ "ขาดความตระหนัก" (หน้า 318)

### การเมือง–อำนาจ (บันไดการมีส่วนร่วม)
- นิยาม: การมีส่วนร่วมต้องนำความเห็นประชาชนไปประกอบการตัดสินใจของรัฐ; หากผู้มีอำนาจตัดสินต่างจากผลการมีส่วนร่วม "ต้องอธิบายได้โดยมีมาตรฐานแห่งความชอบธรรม" (หน้า 322)
- 4 ระดับ (หน้า 322–323): ให้ข้อมูล → เปิดรับความเห็น → วางแผน/ตัดสินใจร่วม (ใช้อนุญาโตตุลาการ/เจรจาในเรื่องที่ขัดแย้งมาก) → พัฒนาศักยภาพการมีส่วนร่วม
- 4 ขั้น (หน้า 323): ร่วมตัดสินใจ → ร่วมดำเนินงาน → ร่วมรับผลประโยชน์ (รวมการกระจายผลบวก/ผลเสียภายในกลุ่ม) → ร่วมประเมินผล
- 5 ระดับ (หน้า 324): ร่วมรับรู้ → ร่วมคิด → ร่วมพิจารณา/ตัดสินใจ → ร่วมดำเนินการ → ร่วมติดตาม ตรวจสอบ ประเมินผล (ประชาชนทำหน้าที่ "เฝ้าระวังและเตือนภัย")
- **"ข้อมูลข่าวสารที่ได้รับนั้นหากมีความไม่ชัดเจน ถูกต้องครบถ้วนแล้ว อาจนำไปสู่ความขัดแย้งที่อาจถึงขั้นรุนแรงได้"** (หน้า 324)
- รัฐต้องให้ข้อมูลและเปิดโอกาสให้ร่วมพิจารณา "รัฐจะยอมให้ประชาชนเข้ามีส่วนร่วมในระดับใด" เป็นตัวแปรสำคัญ (หน้า 323–324)
- 6 ลักษณะ (หน้า 325–326): รับรู้ข่าวสาร (ต้องแจ้ง *ก่อน* ตัดสินใจ) / ปรึกษาหารือ / ประชุมรับฟัง / ประชาพิจารณ์ / มีส่วนร่วมตัดสินใจ / ใช้กลไกกฎหมาย (เรียกร้องสิทธิตามรัฐธรรมนูญเมื่อไม่ได้รับความเป็นธรรม)

### โครงสร้างองค์กร
- เสนอ "กลไกคณะทำงานร่วมระหว่างกลุ่ม" เพื่อประสานประโยชน์และลดความขัดแย้ง (หน้า 327)
- ให้ชุมชนอยู่ในคณะกรรมการ/คณะทำงานของโครงการตั้งแต่ต้นจนจบ (หน้า 329)
- เวทีทางการ เช่น การประชุมคณะกรรมการน้ำ คณะกรรมการศูนย์รวมน้ำ และเวทีไม่เป็นทางการ (หน้า 329)
- ต้องมี "หน่วยเลขานุการ/หน่วยจัดการ" ที่ชัดเจนเป็นตัวเชื่อม (หน้า 329)
- มีผู้เชื่อมประสานท้องถิ่น เช่น กรรมการหมู่บ้าน กรรมการตำบล เชื่อมกับหน่วยงานระดับนโยบาย (หน้า 329)
- กำหนดสัดส่วนกรรมการภาคประชาชนให้เหมาะสม พร้อมบทบาทชัด (หน้า 329)

### เครื่องมือ
- เครือข่ายเฝ้าระวังเตือนภัยในชุมชน ประสานข้อมูลกับหน่วยงานรัฐ เช่น สถานีอุตุนิยมวิทยา และช่องทาง วิทยุ โทรทัศน์ สื่อสังคมออนไลน์ (หน้า 326)
- ฐานข้อมูลทรัพยากรน้ำท้องถิ่นโดย อปท.; การวิจัยชุมชน (สำรวจแหล่งน้ำ ทำฐานข้อมูล) (หน้า 327–328)
- กฎข้อบังคับชุมชนที่มีบทลงโทษใช้ได้จริงอย่างยุติธรรม (หน้า 327)
- ออกแบบการเชื่อมโยงข้อมูลที่ "ประชาชนเข้าใจง่ายและเข้าถึงได้" (หน้า 329)

### ชุมชน
- 4 องค์ความรู้ที่หน่วยงานควรเสริมให้ชุมชน (หน้า 326, อ้างกรมทรัพยากรน้ำ 2556): (1) รู้บริบทพื้นที่ตนเองเรื่องความเสี่ยง (2) เครือข่ายเฝ้าระวัง/เตือนภัย (3) **ซักซ้อมการช่วยเหลือ/อพยพ โดยอพยพกลุ่มเสี่ยงก่อน — คนพิการ ผู้สูงอายุ ผู้ป่วยติดเตียง เด็ก** (4) ร่วมฟื้นฟูหลังน้ำลดกับราชการ/จิตอาสา/เอกชน
- ใช้ประเพณี ความเชื่อ และวันสำคัญเป็นเครื่องมือรวมคน (หน้า 327)

### กระบวนการ — "2 แนวทาง"
- **แนวทาง 1: ภายในชุมชนและระหว่างชุมชน** (หน้า 327–328): 1.1 สร้างความตระหนัก (ความเป็นเจ้าของ, กฎชุมชน, ประเพณี, วันสำคัญ, ฐานข้อมูล, วิจัยชุมชน) → 1.2 แผนบูรณาการเริ่มจากกลุ่ม ขยายเป็นเครือข่ายทั้งตำบล "เพราะการจัดการน้ำที่หนึ่งจะกระทบส่วนอื่นในสายน้ำเดียวกัน" → 1.3 คณะทำงานร่วม → 1.4 กิจกรรมร่วม → 1.5 เยี่ยมเยือนเพื่อลดความขัดแย้ง "เช่นกรณีการทำคันดินกันน้ำตั้งแต่ต้นสาย"
- **แนวทาง 2: องค์กรชุมชน–รัฐ–เอกชน** (หน้า 328–329): 2.1 เป้าหมาย/แผนบูรณาการ แล้วหน่วยงานนำส่วนที่เกี่ยวกับภารกิจไปเป็นแผนงานของตน → 2.2 ความชัดเจนบทบาท ลดซ้ำซ้อน → 2.3 ชุมชนอยู่ในคณะกรรมการ → 2.4 เวทีสม่ำเสมอ → 2.5 ระบบเยี่ยมพื้นที่ สร้างความไว้วางใจ → 2.6 ประเมินผลโครงการรัฐแบบมีส่วนร่วม → 2.7 ข้อมูลเข้าใจง่าย → 2.8 หน่วยเลขานุการ → 2.9 ปัญหาที่ชุมชนเคยเสนอต้องติดตามจริงจัง แม้สำเร็จหรือไม่ก็ต้องกลับมาแลกเปลี่ยน → 2.10 ผู้เชื่อมประสานท้องถิ่น → 2.11 สัดส่วนกรรมการภาคประชาชน
- **หมายเหตุ**: บทความไม่ได้ใช้คำ "ก่อน/ระหว่าง/หลัง" โดยตรง — การจัด 4 องค์ความรู้ (หน้า 326) เป็นก่อน (รู้พื้นที่, เครือข่ายเตือนภัย, ซ้อม) / ระหว่าง (อพยพกลุ่มเสี่ยงก่อน) / หลัง (ฟื้นฟู) เป็นการจัดของผู้สรุป (INSTINCT)

## (e) ข้อจำกัดที่บทความระบุเอง

- การมีส่วนร่วมต้องคำนึงถึงประเภทโครงการ ช่วงเวลา ระดับ และกฎหมายรองรับ (หน้า 326)
- "ร่วมดำเนินการ" อาจทำไม่ได้ในโครงการที่ต้องใช้ผู้เชี่ยวชาญ/เทคโนโลยีสูง (หน้า 324)
- (ข้อสังเกตผู้สรุป) ไม่มีข้อมูลเชิงประจักษ์ ไม่มีการทดสอบว่าแนวทางใดได้ผล เอียงไปทางบริบทชนบท/ลุ่มน้ำ (ฝาย ผักตบ ปลูกป่า) มากกว่าชุมชนเมืองที่พึ่งประตู/ปั๊มของ กทม.

## (f) สิ่งที่ใช้กับสัมมากรได้ทันที (INSTINCT, ≤5)

1. ทำรายชื่อ "อพยพก่อน" (ติดเตียง/ฟอกไต/ผู้พิการ/เด็กเล็ก) รายซอย — เป็นข้อที่บทความระบุชัด (หน้า 326)
2. ใช้บันได 5 ระดับ (หน้า 324) วัดตัวเองว่าสัมมากรอยู่ระดับไหนกับ กทม./เขต: ตอนนี้น่าจะอยู่ "ร่วมรับรู้" บางส่วน เพราะสถานะประตูไม่เผยแพร่
3. ขอให้มี "ผู้เชื่อมประสาน" หนึ่งคนระหว่างหมู่บ้านกับสำนักงานเขต และหนึ่งช่องทางเดียว (หน้า 329 ข้อ 2.8, 2.10)
4. บันทึกทุกคำร้องที่ชุมชนเสนอต่อหน่วยงานพร้อมสถานะติดตาม (หน้า 329 ข้อ 2.9) — ใช้ repo นี้เป็นทะเบียนได้
5. ทำหน้าเว็บให้ "เข้าใจง่ายและเข้าถึงได้" ตามข้อ 2.7 (หน้า 329) — สอดคล้องกับงาน FloodConnect อยู่แล้ว

## (g) คำถามเปิด (OPEN)

- "คณะกรรมการศูนย์รวมน้ำ" (หน้า 329) หมายถึงกลไกใดในโครงสร้างจริง — บทความไม่ขยาย
- ในเขตเมือง กทม. กลไกใดทำหน้าที่ "คณะกรรมการลุ่มน้ำ/คณะทำงานร่วม" ระดับคลอง — ยังไม่มีเอกสาร
- บทความอ้างระเบียบสำนักนายกฯ 2552 แต่ไม่พูดถึงกฎหมายทรัพยากรน้ำฉบับหลัง — สถานะกฎหมายปัจจุบันยังไม่มีเอกสารในคลัง
