## วัตถุประสงค์และขอบเขต (น. ๑๐-๑)

- แนวทางปฏิบัติงานด้านการจัดสรรน้ำ + เพิ่มขีดความสามารถจัดเก็บข้อมูลในระบบฐานข้อมูลมาตรฐาน — คำนวณ
  ประสิทธิภาพการชลประทานและวิเคราะห์ดัชนีการส่งน้ำ แล้วจัดทำรายงานการจัดสรรน้ำถึงระดับโซน
- ครอบคลุมการติดตาม วางแผน และประเมินผลการส่งน้ำรายสัปดาห์ โดยใช้โปรแกรม **WASAM** — เพิ่มประสิทธิภาพ
  การใช้น้ำของเกษตรกร (ปลูกพืช เลี้ยงปลา เลี้ยงสัตว์อื่นๆ)

## คำจำกัดความ (น. ๑๐-๑)

แผนการส่งน้ำ = แผนแสดงรายละเอียดกำหนดการส่งน้ำ ระยะเวลาส่งน้ำ ปริมาณน้ำที่ส่งแต่ละสัปดาห์ กิจกรรมเพาะปลูก
และปริมาณน้ำที่ใช้ทั้งฤดูกาล — ใช้ข้อมูล: ค่าการใช้น้ำของพืช (ETc), สัมประสิทธิ์การใช้น้ำของพืช (Kc), อัตราการ
รั่วซึมบนแปลงนา, ฝนใช้การ (Effective Rainfall), ประสิทธิภาพการชลประทาน, ปริมาณน้ำต้นทุน — แบ่งเป็น
1. แผนการส่งน้ำฤดูนาปี (ฤดูฝน) — พื้นที่เพาะปลูกใช้ข้อมูลพื้นที่เพาะปลูกทั้งโครงการได้เลย
2. แผนการส่งน้ำฤดูแล้ง (พืชฤดูแล้ง) — ต้องกำหนดพื้นที่เป้าหมายให้สอดคล้องกับน้ำต้นทุน โดยประธานกลุ่มผู้ใช้น้ำ
   เป็นผู้สำรวจกับสมาชิกในกลุ่ม

## กระบวนงาน 3 ช่วง (น. ๑๐-๒)

**ก่อนส่งน้ำ**: สำรวจความต้องการเพาะปลูก (ประธานกลุ่มผู้ใช้น้ำ) → สำรวจสภาพอาคารชลประทาน → ตรวจสอบการ
ขุดลอกคูส่งน้ำ → ประชุมวางแผนรับน้ำ (กำหนดรอบเวรรับน้ำ) → จัดทำแผนส่งน้ำรายฤดู → **แจ้งข่าวประชาสัมพันธ์
ให้เกษตรกรกลุ่มผู้ใช้น้ำทราบ** → ประชุมชี้แจงแผนกับกลุ่มผู้ใช้น้ำ
**ระหว่างส่งน้ำ**: เปิด ปตร. ตามปริมาณที่ต้องการ → บังคับน้ำในคลองสายต่างๆ (พนักงานส่งน้ำ) → ส่งน้ำเข้าคูส่งน้ำ
(พนักงานส่งน้ำ+ประธานกลุ่ม) → ให้น้ำแก่พืชตามที่ต้องการ (เกษตรกร) → สำรวจพื้นที่เพาะปลูก (พนักงานส่งน้ำ) →
รายงานผล → พนักงานส่งน้ำ → สบ.คบ. → จน.คบ. → วางแผนสัปดาห์ถัดไป
**สิ้นสุด**: รวบรวมข้อมูลการส่งน้ำ+ปริมาณน้ำที่ใช้ทั้งฤดู → สรุปพื้นที่เพาะปลูกแต่ละชนิด → ประเมินมูลค่าผลผลิต →
คำนวณประสิทธิภาพชลประทาน → จัดทำรายงานผลการจัดสรรน้ำประจำปี

## หน้าที่ความรับผิดชอบ (น. ๑๐-๔)

หัวหน้าฝ่ายบริหารและจัดการน้ำ (ฝจน.ชป.) — รวบรวมข้อมูลรายสัปดาห์+วางแผน+รายงานผลของโครงการในสังกัด
สำนักชลประทาน เสนอ ผส.ชป. เพื่อพิจารณาตัดสินใจ; หัวหน้าฝ่ายจัดสรรน้ำและปรับปรุงระบบชลประทาน (ฝจน.คป./
ฝจน.คบ.) — เสนอ ผอ.โครงการเพื่อพิจารณาตัดสินใจ

## ผังกระบวนการ (น. ๑๐-๕) — วนซ้ำรายสัปดาห์ ยึดวันพุธ/พฤหัสบดี

1. เริ่มกระบวนการข้อมูลพื้นฐาน (สัปดาห์แรกของฤดู) — ปริมาณการใช้น้ำของพืชอ้างอิง, ฝนคาดการณ์, ระบบคลอง
   ชลประทาน, ค่าสัมประสิทธิ์พืช, แผนการเพาะปลูก
2. นำเข้าโปรแกรม WASAM เพื่อวางแผนการจัดสรรน้ำรายสัปดาห์ (**ทุกวันพุธ**) — ฝนตกจริงสัปดาห์ปัจจุบัน,
   รายงานสภาพน้ำพื้นที่เพาะปลูก, ประเมิน/วิเคราะห์ผลการส่งน้ำรายสัปดาห์
3. วิเคราะห์ข้อมูลและประเมินสถานการณ์การส่งน้ำ — รายงานผลจำลองความต้องการน้ำ+แผนส่งน้ำระดับคลองสายใหญ่/
   คลองสายซอย ส่งต่อ ผอ.คป./ผอ.คบ. → ฝจน.คป./ฝจน.คบ. → พนักงานส่งน้ำ
4. บริหารจัดการตามแผน (ทุกสัปดาห์)
5. สิ้นสุดฤดูแล้ง/ฝน (สัปดาห์สุดท้าย) — รายงานผลการวางแผนส่งน้ำประจำฤดู

**คำแนะนำเดินเอกสารทุกสัปดาห์: วันพุธเก็บข้อมูลฝน/สภาพน้ำ → วันพฤหัสบดีดำเนินการส่งน้ำตามแผน + วัด
ปริมาณน้ำจริงรายวันที่จุดตรวจวัด → เปรียบเทียบวิเคราะห์ → กลับไปวันพุธสัปดาห์ถัดไป** — นี่คือ **cadence
รายสัปดาห์ที่ชัดเจนที่สุด** ในชุดคู่มือ 16 เล่มเท่าที่อ่านมา

- `AG_RID`, `AG_PROV_RID`, `AS_RID_RANGSIT`, `AS_RID_COAST` (ระบบคลองชลประทาน), `DC_RID_DIVERT`
  (ผันน้ำ/เปิดปิดประตูระบบชลประทาน) — เล่มนี้คือ SOP ที่แน่นอนที่สุดของการตัดสินใจเปิด/ปิดประตูระดับโครงการ
  ชลประทาน (ไม่ใช่ระดับ กทม.) และยืนยันว่าเป็น cadence **รายสัปดาห์** (วันพุธ/พฤหัสบดี) ไม่ใช่ real-time
- `CH_RID_HOTLINE` ไม่ปรากฏในเล่มนี้ — ช่องทางสื่อสารที่ระบุคือ "แจ้งข่าวประชาสัมพันธ์" ให้กลุ่มผู้ใช้น้ำ
  (ระดับหมู่บ้าน/กลุ่มเกษตรกร) ตรงกับที่พบในเล่ม 11 (หอกระจายข่าว/บอร์ดหมู่บ้าน)

## สิ่งที่ FloodConnect จะใช้ได้ (INSTINCT)

- สมการ ETc/q/Q เป็นสูตร "ห่วงโซ่จัดสรรน้ำเกษตร" มาตรฐานที่ RID ใช้ (Kc/ETo จากเล่ม 7/15, ฝนใช้การจาก
  เล่ม 6, ประสิทธิภาพชลประทานจากเล่ม 15) — ครบวงจรตั้งแต่ต้องการใช้น้ำจริงจนถึงปริมาณต้องส่งที่ประตูระบาย
- ข้อมูลที่ WASAM สร้างขึ้น (รายงาน 3 ระดับ: หัวหน้าโครงการ/หัวหน้างานส่งน้ำ/พนักงานส่งน้ำ, รายสัปดาห์)
  **เป็นข้อมูลที่ RID มีอยู่แล้วในระบบภายในแต่ไม่เผยแพร่สาธารณะ** — ดัชนีวัดผลการส่งน้ำระดับโซน/งานส่งน้ำ/
  โครงการ ถ้าเปิดเผยจะเป็นฟีดที่มีประโยชน์ต่อการเข้าใจภาพรวมน้ำต้นทุนก่อนถึงฤดูน้ำหลาก แต่ไม่ใช่ real-time
  สถานะประตูที่ FloodConnect ต้องการโดยตรง
