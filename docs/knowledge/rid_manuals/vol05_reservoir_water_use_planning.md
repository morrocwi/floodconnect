## วัตถุประสงค์และขอบเขต (น. ๕-๑)

- เครื่องมือช่วยวางแผนการจัดสรรน้ำ **สำหรับโครงการที่มีอ่างเก็บน้ำ และไม่มีอ่างเก็บน้ำ** ทั้งสองกรณี
- ครอบคลุมการบริหารจัดการน้ำช่วงฤดูฝนและฤดูแล้งของโครงการชลประทาน/โครงการส่งน้ำและบำรุงรักษา — 2 กรณี:
  1. มีอ่างเก็บน้ำ: วางแผนจากพื้นที่เพาะปลูก → คำนวณปริมาณการใช้น้ำ → คำนวณเป็นปริมาณน้ำในอ่างทั้งปี เพื่อ
     คาดการณ์ว่าเพียงพอต่อการเพาะปลูกหรือไม่
  2. ไม่มีอ่างเก็บน้ำ: วางแผนจากพื้นที่เพาะปลูก → คำนวณปริมาณการใช้น้ำรายวันและปริมาณน้ำส่งสะสม

## คำจำกัดความ (น. ๕-๑)

การวางแผนการใช้น้ำจากอ่างเก็บน้ำ = คิดคำนวณหาปริมาณความต้องการใช้น้ำชลประทานในทุกภาคส่วน แล้วนำมา
วางแผนการจัดสรรน้ำให้สอดคล้องกับปริมาณน้ำต้นทุนที่มีอยู่ โดยไม่ขาดแคลนน้ำหรือเกิดการขาดแคลนน้อยที่สุด

## หน้าที่ความรับผิดชอบ (น. ๕-๑, ๕-๒) — ห่วงโซ่การตัดสินใจ 9 ชั้น

| ตำแหน่ง | บทบาท |
|---|---|
| ผู้อำนวยการสำนักบริหารจัดการน้ำและอุทกวิทยา (ผส.บอ.) | รับทราบ+ตรวจสอบผลของสำนักชลประทานที่ 1-17 |
| ผู้อำนวยการสำนักชลประทานที่ 1-17 (ผส.ชป.) | รับทราบ+ตรวจสอบผลของโครงการในสังกัด |
| ผู้อำนวยการส่วนบริหารจัดการน้ำ (ผจน.) | วางแผน+ติดตามผลของสำนักชลประทานที่ 1-17 |
| ผู้อำนวยการส่วนจัดสรรน้ำและบำรุงรักษา สำนักชลประทานที่ 1-17 (ผบร.) | วางแผน+ติดตามผลของโครงการในสังกัด |
| หัวหน้ากลุ่มงานจัดสรรน้ำ (กจ.จน.) | วางแผน+รายงานผลของสำนักชลประทานที่ 1-17 |
| หัวหน้าศูนย์ปฏิบัติการจัดสรรน้ำ (ศป.จน.) | วางแผน+รายงานผลของสำนักชลประทานที่ 1-17 |
| หัวหน้าฝ่ายบริหารและจัดการน้ำ (ฝจน.ชป.) | วางแผน+รายงานผลของโครงการในสังกัดสำนักชลประทาน |
| หัวหน้าฝ่ายจัดสรรน้ำและปรับปรุงระบบชลประทาน (ฝจน.คป./ฝจน.คบ.) | วางแผน+จัดทำรายงานผลของโครงการชลประทาน/โครงการส่งน้ำ |
| หัวหน้าฝ่ายส่งน้ำและบำรุงรักษา (ฝสบ.คป/ฝสบ.คบ.) | วางแผน+จัดทำรายงานผลของโครงการชลประทาน/โครงการส่งน้ำ |

## ผังกระบวนการ (น. ๕-๓) — รวม ~16 วัน ต่อรอบฤดู

1. เริ่มกระบวนการรวบรวมข้อมูลพื้นฐาน (7 วัน) — กำหนดขอบเขตพื้นที่ + รวบรวมตามคู่มือเล่ม 1/16
2. คำนวณโดยใช้โปรแกรม Reservoir Operation Study (1 วัน) — ใส่ข้อมูลแผนเพาะปลูก
3. พิจารณาปริมาณน้ำที่ใช้กับน้ำต้นทุน (1 วัน) — ประเมิน/วิเคราะห์ว่าสอดคล้อง/เหมาะสมหรือไม่ (ถ้าไม่ใช่ วนกลับ
   ไปคำนวณใหม่)
4. สรุปแผนการจัดสรรน้ำ (7 วัน) — จัดทำแผนแต่ละฤดูกาล + เอกสารเสนอกรมอนุมัติ — ผู้รับผิดชอบ: ผส.บอ., ผส.ชป.
   1-17, ผจน., ผบร.ชป., กจ.จน., ศป.จน., ฝจน.ชป.

## เครื่องมือ — โปรแกรม Reservoir Operation Study (Excel)

- 3 ชีตหลักที่ต้องกรอก: **fill_data** (ข้อมูลทั่วไป: ชื่ออ่าง, สำนักชลประทานที่, ปริมาณน้ำในอ่าง ณ วันที่กำหนด,
  ประสิทธิภาพโครงการ, จังหวัด, ค่า ETo ของจังหวัด, ปริมาณน้ำรั่วซึม), **ROS**, **การใช้ที่ดิน**
- กรอกเฉพาะ cell พื้นสีเหลืองอ่อนเท่านั้น (ป้องกันแก้ไขสูตรผิด)
- ตัวอย่างค่ารั่วซึม: ภาคกลาง 7 มม./สัปดาห์, ภาคอื่นๆ 14 มม./สัปดาห์ — สอดคล้องกับเล่ม 15 (1.0/2.0/1.5 มม./วัน)
  แต่หน่วยเป็นรายสัปดาห์ (ต้องแปลงหน่วยก่อนเทียบ — INSTINCT, ยังไม่ได้ตรวจว่าตรงกันจริง)

## ความเกี่ยวข้องกับ DAG (`docs/knowledge/WATER_SYSTEM_DAG.md`)

- `AS_DAM_RID`, `DT_DAM`, `AG_RID`, `AG_PROV_RID` — เช่นเดียวกับเล่ม 4 (Reservoir Operation Simulation)
  เล่มนี้เป็นคู่แฝดระดับ **แผนก่อนฤดูกาล** (ROS ทำครั้งเดียวต้นฤดู 16 วัน) ต่างจากเล่ม 4 ที่ปรับปรุงรายสัปดาห์
- ไม่พบเส้นเชื่อมตรงไปยัง `CH_*`/`PP_*` (ช่องทางถึงประชาชน/ผู้รับผล) ในส่วนที่อ่าน

## สิ่งที่ FloodConnect จะใช้ได้ (INSTINCT)

- ยืนยันภาพ 2 โปรแกรมคู่กัน: **ROS** (วางแผนก่อนฤดู, เล่ม 5) → **Reservoir Operation Simulation**
  (ปรับปรุงรายสัปดาห์ระหว่างฤดู, เล่ม 4) — ทั้งคู่เป็นเครื่องมือวางแผนน้ำต้นทุนเกษตร ไม่ใช่เครื่องมือเตือนภัยน้ำท่วม
  เมือง แต่แสดงว่า RID มีข้อมูลปริมาณน้ำในอ่างและแผนระบายล่วงหน้าเป็นรายสัปดาห์อยู่แล้วในระบบภายใน
