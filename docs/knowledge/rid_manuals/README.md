## ข้อสังเกตข้ามเล่ม

- **สูตรประตูระบาย free/submerged ไม่ตรงกันระหว่างเล่ม 13 และ 14**: เล่ม 13 (vol13-eq5/eq6) ใช้ $h = Y - 0.60G_o$ และคูณ $G_o$ ในกรณีจม; เล่ม 14 (vol14-eq6/eq7) ใช้ $H$ เต็ม และคูณ $h_s$ ในกรณีจม. ต้องจับคู่สูตรกับวิธีที่ใช้หาสัมประสิทธิ์ให้ตรงกัน.
- ความไม่สอดคล้องภายในเล่ม 13: vol13-eq11, eq20, eq23 (ดูการ์ด).
- เล่ม 14 สูตรความเร็วเฉลี่ยสำหรับความลึก ≥ 2.5 m พิมพ์ด้วยฟอนต์เสีย (OPEN).
- ไม่มีเล่มใดที่ถอดแล้วมีปีพิมพ์ระบุ; ไฟล์ต้นทางเป็นการรวมเล่มภายหลัง.
