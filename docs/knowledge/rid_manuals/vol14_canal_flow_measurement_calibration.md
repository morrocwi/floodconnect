## วัตถุประสงค์และขอบเขต (น. 14-1)

- วัดปริมาณน้ำในคลองส่งน้ำและสอบเทียบอาคารชลประทาน เพื่อตรวจสอบปริมาณน้ำที่ไหลผ่านอาคาร
- ครอบคลุมการวัดด้วย **เครื่องวัดกระแสน้ำ (current meter)** และการสอบเทียบอาคารของโครงการชลประทาน/โครงการส่งน้ำและบำรุงรักษา
- นิยาม "การสอบเทียบ (Calibration)": หาสัมประสิทธิ์การไหลผ่านอาคาร โดยหาความสัมพันธ์ระหว่างปริมาณน้ำกับระดับน้ำเหนือ–ท้ายอาคาร ระยะเปิดบาน ฯลฯ แล้วจัดทำเป็นตารางหรือ **Calibration Curve / Rating Curve** ของอาคารนั้น

## กระบวนการ (ผังกระบวนการ น. 14-2; ขั้นตอน น. 14-2–14-3)

1. **รวบรวมข้อมูลและเตรียมงาน** (ก่อนฤดูกาลส่งน้ำ; ฝสบ.)
   1.1 รวบรวมรูปตัดขวางลำน้ำ ข้อมูลชลศาสตร์ของอาคาร ค่าระดับต่างๆ
   1.2 เตรียมเครื่องวัดความเร็วกระแสน้ำที่ **ผ่านการตรวจสอบปรับเทียบแล้ว**
   1.3 ตรวจค่าระดับของอาคาร (ระดับธรณีประตู, FSL) และตรวจแผ่นระดับน้ำ (แนวตั้ง/แนวเอียง) ทั้งเหนือและท้ายน้ำให้อยู่ในระดับที่ถูกต้อง
   1.4 ปรับตั้งค่าศูนย์ของบาน — ระยะเปิดบานอ่านได้ศูนย์เมื่อบานปิดและน้ำไหลผ่านไม่ได้
   1.5 เลือกสถานที่วัด: ห่างจากอาคารพอสมควร ทางน้ำตรง น้ำไหลราบเรียบ ไม่ปั่นป่วน **ไม่ได้รับอิทธิพลจาก backwater** ไม่มีสิ่งกีดขวาง
2. **ตรวจวัดปริมาณน้ำและสอบเทียบอาคาร** (ตลอดฤดูกาลส่งน้ำ; ฝสบ.)
   2.1 สำรวจรูปตัด → 2.2 แบ่งหน้าตัดเป็นช่วง วัดความลึกแต่ละแนวดิ่ง → 2.3 บันทึกข้อมูลอาคาร (จำนวนบานที่เปิด, ชนิดช่องระบาย ท่อกลม/เหลี่ยม/ประตู, จำนวนช่อง/แถว, ขนาดช่อง, ระดับธรณีประตู) → 2.4 บันทึกระดับน้ำเหนือ–ท้าย, ความต่างระดับ, ระยะเปิดบาน → 2.5 วัดความเร็วตามความลึกต่างๆ ตามเกณฑ์ → 2.6 **ปรับการเปิดบานหลายระยะ** เพื่อได้ปริมาณน้ำทดสอบหลายค่า
3. **คำนวณปริมาณน้ำและหาสัมประสิทธิ์การไหล** (ฝจน.)
   3.1 ความเร็วเฉลี่ย → 3.2 พื้นที่หน้าตัดย่อย → 3.3 อัตราการไหลรวม → 3.4 นำ Q ที่ได้ไปคำนวณสัมประสิทธิ์ → 3.5 นำ C_s แต่ละครั้งไปหาความสัมพันธ์กับ h_s/G_o **บนกราฟ log-log** → 3.6 ใช้สมการความสัมพันธ์ทำ **ตารางปริมาณน้ำผ่านอาคารที่ระยะเปิดบานต่างๆ**
4. **สรุปรายงาน** (สิ้นฤดูกาลส่งน้ำ; ฝจน.)

มาตรฐานงาน (น. 14-3): ข้อมูลคลอง/อาคารถูกต้อง; เครื่องวัดสอบเทียบก่อนใช้; แผ่นระดับน้ำตั้งถูกระดับ; วิธีวัดถูกต้อง; ใช้สูตรตรงชนิดอาคารและลักษณะการไหล; **ความสัมพันธ์ C_s กับ h_s/G_o ต้องมี R² อยู่ระหว่าง 0.8–1.0**; ส่งรายงานผู้อำนวยการโครงการ.
แบบฟอร์ม: "-" (ไม่มี).

## เครื่องมือ

- Current meter แบบถ้วยหมุนรอบแกนตั้ง (Pygmee) — กระแสน้ำความเร็วไม่สูง; แบบใบพัด (A-OTT) — กระแสน้ำความเร็วสูง (น. 14-6, 14-7). เครื่องวัดความเร็วไม่ได้โดยตรง แต่นับรอบต่อเวลา แล้วแปลงด้วยสูตรของเครื่อง.
- แผ่นระดับน้ำ (staff gauge) แนวตั้ง/แนวเอียง เหนือและท้ายอาคาร; ค่าระดับธรณีประตูและ FSL.

**vol14-eq1** — สมการความต่อเนื่องที่หน้าตัด (น. 14-6)
$Q = A\,V$; Q [m³/s]; A = พื้นที่หน้าตัดตั้งฉากทิศการไหล [m²]; V = ความเร็วเฉลี่ยผ่านหน้าตัด [m/s].

**vol14-eq2** — สมการเครื่องวัดกระแสน้ำ (น. 14-7)
$V = a\,N + b$; V [m/s]; N = จำนวนรอบต่อวินาที; a, b = ค่าคงที่ของเครื่อง (เปลี่ยนตามชนิดและขนาดเครื่อง).
Toledo: not yet looked up — do not use in a derivation until registered (PROP or CANONICAL)

**vol14-eq3** — ความเร็วเฉลี่ยในแนวดิ่งตามความลึก d (น. 14-8); ความลึกวัดจากผิวน้ำ
| ความลึก d [m] | จุดวัด | สูตร |
|---|---|---|
| d ≤ 0.6 | 1 จุด: 0.6d | $V_m = V_{0.6d}$ |
| 0.6 < d < 1.0 | 2 จุด: 0.2d, 0.8d | $V_m = (V_{0.2d} + V_{0.8d})/2$ |
| 1.0 < d < 2.5 | 3 จุด: 0.2d, 0.6d, 0.8d | $V_m = (V_{0.2d} + 2V_{0.6d} + V_{0.8d})/4$ |
| d ≥ 2.5 | ผิวน้ำ, 0.2d, 0.4d, 0.6d, 0.8d, ท้องน้ำ | **สูตรในต้นฉบับพิมพ์ด้วยฟอนต์เสีย อ่านไม่ได้ครบ** — ส่วนที่อ่านได้: มีพจน์ $(V_s + V_b)$, ตัวเลข 1 และ 10 ในส่วนหน้า, และพจน์ $(V_{0.2d}+V_{0.4d}+V_{0.6d}+V_{0.8d})$ หาร 4 — **OPEN: ห้ามเติมสูตรเองจนกว่าจะได้ต้นฉบับที่อ่านได้** |

V_s = ความเร็วที่ผิวน้ำ; V_b = ความเร็วที่ท้องน้ำ; V_{kd} = ความเร็วที่ความลึก kd จากผิวน้ำ. หมายเหตุ: ช่วง d = 1.0 พอดีไม่ถูกครอบคลุมโดยเครื่องหมาย < ทั้งสองข้าง (ตามต้นฉบับ).
หลักการแบ่งหน้าตัด (น. 14-8): แต่ละส่วนย่อยควรมีปริมาณการไหล **ไม่เกิน 10%** ของปริมาณรวม; ความกว้างส่วนย่อยไม่จำเป็นต้องเท่ากัน.
Toledo: not yet looked up — do not use in a derivation until registered (PROP or CANONICAL)

**vol14-eq4** — Mean-section Method (น. 14-9)
จุดวัด 1…6 (ขอบ 0 และ 7 มี V=0, d=0):
$\bar V_{i,i+1} = 0.5(V_i + V_{i+1})$; $A_{i,i+1} = 0.5(d_i + d_{i+1})\,W_{i+1}$; $Q_{i,i+1} = \bar V_{i,i+1} A_{i,i+1}$; $Q = \sum Q_{i,i+1}$.
d_i = ความลึกที่แนวดิ่ง i [m]; W = ความกว้างส่วนย่อย [m]; V_i = ความเร็วเฉลี่ยในแนวดิ่ง i (จาก eq3).
Toledo: not yet looked up — do not use in a derivation until registered (PROP or CANONICAL)

**vol14-eq5** — Mid-section Method (น. 14-10)
$A_i = 0.5(W_i + W_{i+1})\,d_i$; $Q_i = A_i V_i = 0.5(W_i + W_{i+1})\,d_i V_i$; $Q = \sum_i Q_i$.
Toledo: not yet looked up — do not use in a derivation until registered (PROP or CANONICAL)

**vol14-eq6** — ประตูระบาย, ท้ายประตูเป็น Free Flow (ระดับน้ำท้ายไม่มีผล) (น. 14-11)
$Q = C_d\,L\,G_0\,\sqrt{2 g H}$; C_d = สัมประสิทธิ์เมื่อ free flow; L = ความกว้างช่องการไหล [m]; G₀ = ระยะเปิดบาน [m]; H = ระดับน้ำเหนือน้ำ − ระดับธรณีประตู [m]; g = 9.81 m/s²; Q [m³/s].
**ต่างจาก vol13-eq5** (เล่ม 13 ใช้ h = Y − 0.60 G_o; เล่ม 14 ใช้ H เต็ม) — ความต่างระหว่างเล่ม ถอดตามต้นฉบับทั้งคู่.
Toledo: not yet looked up — do not use in a derivation until registered (PROP or CANONICAL)

**vol14-eq7** — ประตูระบาย, ท้ายประตูเป็น Submerged Flow (ระดับน้ำท้ายมีผล) (น. 14-11)
$Q = C_s\,L\,h_s\,\sqrt{2 g\,\Delta H}$; C_s = สัมประสิทธิ์ (มีความสัมพันธ์กับ h_s/G_o); h_s = ความลึกท้ายน้ำ = ระดับท้ายน้ำ − ระดับธรณีประตู [m]; ΔH = ระดับเหนือน้ำ − ระดับท้ายน้ำ [m]; G_o = ระยะเปิดบาน [m].
**ต่างจาก vol13-eq6**: เล่ม 13 คูณ G_o, เล่ม 14 คูณ h_s. ตัวอย่างที่ 2 ของเล่ม 14 คำนวณตามแบบ h_s (ตรวจเลขคณิตแถวแรก: 0.534 / (1.00 × 0.407 × 3.4793) ≈ 0.377 ตรงกับ C_s ในตาราง — MEASURED, เป็นการตรวจการถอด ไม่ใช่การตรวจความถูกต้องของสูตร).

**vol14-eq8** — ความสัมพันธ์สอบเทียบ (น. 14-3, 14-12, 14-13)
ขั้นตอน 6.3.5: หาความสัมพันธ์ C_s กับ h_s/G_o บนกราฟ log-log → สมการกำลัง. ตัวอย่างในเล่ม:

## ข้อมูลที่ต้องใช้

รูปตัดขวางลำน้ำ; ค่าระดับธรณีประตูและ FSL; แผ่นระดับน้ำเหนือ–ท้ายที่ตรวจระดับแล้ว; ขนาด/จำนวน/ชนิดช่องบาน; ระยะเปิดบาน (ตั้งศูนย์แล้ว); ความเร็วกระแสน้ำหลายความลึกหลายแนวดิ่ง; **ชุดข้อมูลหลายระยะเปิดบาน** ต่ออาคาร.

## ข้อจำกัดที่เล่มระบุ/ที่พบ

- จุดวัดต้องไม่อยู่ในอิทธิพล backwater (น. 14-2) — ในคลองระบายน้ำเมืองช่วงน้ำหลาก เงื่อนไขนี้อาจหาได้ยาก (INSTINCT).
- สูตรความเร็วเฉลี่ย d ≥ 2.5 m อ่านไม่ได้ (ฟอนต์เสีย) — OPEN.
- สูตร free/submerged ของเล่ม 14 ต่างจากเล่ม 13 (ดู eq6, eq7) — ต้องเลือกให้ตรงกับวิธีที่ใช้หาสัมประสิทธิ์.
- สัมประสิทธิ์และสมการสอบเทียบเป็นของเฉพาะอาคาร.

## สิ่งที่ FloodConnect จะใช้ได้ (INSTINCT, ≤5)

- vol14-eq7 + vol14-eq8 คือสูตรที่ต้องใช้ถ้าจะแปลงส่วนต่างระดับน้ำที่ ปตร.มีนบุรีเป็นอัตราการไหล — ขาด: ความกว้างช่องบานและจำนวนบาน, ระดับธรณีประตู (หา h_s), ระยะเปิดบาน G_o ณ เวลาเดียวกัน, และ **สมการสอบเทียบ C_s(h_s/G_o) ของอาคารนั้น** (หน่วยงานเจ้าของอาคารอาจมี — ยังไม่ได้ถาม).
- ตัวอย่างทั้งสองแสดงว่า C ผันแปรเกือบ 2 เท่าตามระยะเปิดบาน — ใช้ค่า C คงที่ค่าเดียวจะให้ผลคลาดมาก; ถ้าไม่มีสมการสอบเทียบ ควรแสดงผลเป็นช่วง.
- ตารางตัวอย่างเป็นรูปแบบข้อมูลที่ดีสำหรับ schema ของการบันทึก "ระดับเหนือ/ท้าย/ธรณี/ระยะเปิดบาน/Q" ถ้าจะขอข้อมูลจากผู้ดูแล ปตร.
- Mean/Mid-section (eq4/eq5) ใช้ได้ถ้าชุมชน/อาสาวัดความเร็วในคลองจริง — ต้องมี current meter ที่ปรับเทียบแล้ว.
