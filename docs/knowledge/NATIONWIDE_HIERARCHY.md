## คำแก้ไขต่อ C1 (การเรียกชื่อปัญหาใหม่ให้ตรง)

**เดิม (`REVIEW_7_CLAIMS_2026-09-27.md#C1`)**: "ในเขตเมือง/กทม. ... การประกาศเตือนภัยและคำสั่งมีผู้สั่งการ
หลายหน่วยงานพร้อมกันจริง; ส่วนกรอบกฎหมายระดับจังหวัด/ลุ่มน้ำมีลำดับชั้นทางการชัดเจนกว่า"

**คำแก้ไข (founder, 2026-09-27, ต่อยอดจากส่วนขยายรอบนี้)**:

> **ปัญหาไม่ใช่ "เฉพาะเขตเมือง" แต่คือรอยต่อระหว่างชั้นของไฮราคีทั้งประเทศ**

กล่าวคือ: ระบบไม่ได้เป็น "จังหวัดมีเจ้าภาพชัด vs. กทม.ไม่มีเจ้าภาพ" สองระบบแยกกัน — แต่เป็น **ไฮราคีเดียว
ต่อเนื่องกันตามสายน้ำ** (เขื่อนต้นน้ำ → ลุ่มน้ำ → แม่น้ำสายหลัก → จังหวัด → กทม. → เขต/หมู่บ้าน) ที่แต่ละ
ชั้นมีเจ้าภาพตามกฎหมายของตัวเองจริง (ตรงกับที่การ์ดน่านแสดง) **แต่ไม่มีกลไก handoff ที่ระบุไว้ชัดระหว่างชั้น**
— เมื่อ TIER-2/3 ตัดสินใจปล่อย/ผันน้ำ ไม่มีเอกสารยืนยันว่าแจ้ง TIER-4 (จังหวัด) หรือ TIER-5 (กทม.) ล่วงหน้า
เท่าไร, ไม่มีกติกาแบ่งภาระ, ไม่มีกติกาชดเชย — 3 ช่องว่างนี้ซ้ำกันทุกรอยต่อที่ตรวจ (ตาราง HANDOFF ข้างบน)
C1 เดิมจับได้แค่ "ปลายทาง" ของปัญหา (กทม. มีผู้สั่งหลายรายพร้อมกัน) แต่ไม่ได้จับ "ต้นตอโครงสร้าง" ซึ่งคือ
การไม่มีสัญญาสัญญาณ/ข้อมูล/กติกาที่ไหลข้ามชั้นไฮราคีลงมา — ดู "correction" ที่ต่อท้าย C1 ใน
`REVIEW_7_CLAIMS_2026-09-27.md`
