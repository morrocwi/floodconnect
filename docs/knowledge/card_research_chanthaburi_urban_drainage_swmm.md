## อธิบายอะไรเกี่ยวกับ node/สถานีที่โปรเจกต์ติดตาม

**ไม่ใช่**เอกสารเกี่ยวกับ กทม./สัมมากร — กรณีศึกษาคือเทศบาลเมืองจันทบุรี (15 ชุมชน) — **ใช้เป็นหลักฐาน
เชิงกลไก (mechanism evidence) สำหรับ (ก) การแปลงปริมาณฝนเป็นการระบาย/น้ำท่วมขังด้วยแบบจำลอง
อุทกวิทยาเมือง (SWMM) และ (ข) ตัวอย่างจริงของ "ปริมาณฝนสูงสุดในรอบ 30 ปี" เป็นเกณฑ์เลือก event
สำหรับประเมินขีดความสามารถระบบระบายน้ำที่มีอยู่** — ใช้เทียบเคียงวิธีคิดกับ PROP-FLOOD-06's `F_H(U)`
term ได้ แต่ตัวเลขเป็นของจันทบุรี ไม่ใช่ของ node ที่โปรเจกต์ติดตาม

## Findings (สรุปตรงประเด็น, พร้อมหน้า)

1. **วิธีการเลือก design event**: เลือกวันที่มีปริมาณน้ำฝนรายวันสูงสุดในรอบ 30 ปี (พ.ศ. 2531-2561)
   คือ 23 กรกฎาคม 2556 (ช่วงอิทธิพลพายุโซนร้อนเซบี) จากข้อมูลเรดาร์ตรวจอากาศสถานีระยอง กรม
   อุตุนิยมวิทยา — **ปริมาณฝนรายชั่วโมงสูงสุดที่พบ คือ 90-100 มิลลิเมตร/ชั่วโมง ช่วงเวลา 10:00 น.** (น.
   404-405, "รูปที่ 2") — ปีนั้นปริมาณฝนรวมทั้งปี 3,711.2 มิลลิเมตร (สถิติปกติของสถานีจันทบุรี, ไม่ใช่ปี
   ผิดปกติเมื่อดูรายปี แต่ event เดี่ยววันนั้นรุนแรง) (น. 404)
2. **ผลการจำลอง SWMM 5**: น้ำท่วมขังลึกสุดประมาณ **0.82 เมตร** บริเวณถนน/ที่อยู่อาศัยชุมชนที่ 6 (วัด
   ใหม่เมืองจันท์) — สาเหตุ: พื้นที่เป็นแอ่ง ไม่มีพื้นที่ให้น้ำซึมผ่านลงใต้ดิน (บทคัดย่อ, น. 404)
3. **ค่าสัมประสิทธิ์การไหล (runoff coefficient) ตามประเภทสิ่งปกคลุมดิน** (Table 1, น. 406-407,
   Manning's N-based ไม่ใช่ค่า c แบบ rational-method โดยตรง แต่ใช้แปลงพื้นที่รับน้ำในแบบจำลอง):
   พื้นที่ชุมชนหนาแน่นปานกลาง (Settlement) 0.0678, ดินเปล่า (Bare soil) 0.0113, แหล่งน้ำ (Pond)
   0.0010, พื้นที่สีเขียว (Green space, light shrub) 0.368 — **หมายเหตุสำคัญ: นี่คือ Manning's
   roughness coefficient ของแบบจำลอง SWMM ไม่ใช่ runoff coefficient `c` แบบเดียวกับที่
   PROP-FLOOD-06 อ้างถึง (bound pair [0.5, 1]) — ห้ามนำตัวเลขนี้ไปแทนค่า `c_U` โดยตรง เป็นคนละนิยาม**
4. **ข้อเสนอแก้ไข**: เพิ่มพื้นที่สีเขียว + ปรับพื้นผิว (ถนน/ทางเท้า) ให้น้ำซึมผ่านได้ แทนการเพิ่มความจุท่อ
   อย่างเดียว (บทคัดย่อ)
5. **โครงสร้างท่อระบายที่พบจริงในพื้นที่ศึกษา** (น. 417): box culvert 150×150×250 ซม. ตามถนน
   เลียบเนิน/ถนนพระยาตรัง, ท่อกลม (circular) เส้นผ่านศูนย์กลาง 1,000 ซม. (=10 ม.) ตามถนนทั่วไป —
   ตัวเลขระดับ "โครงสร้างท่อระดับเทศบาลขนาดกลาง" ใช้เทียบสัดส่วนกับความจุ pump station ของสัมมากร
   ได้ (บริบทเชิงขนาด ไม่ใช่ตัวเลขที่ใช้แทนกันได้)

## ทำไมเกี่ยวข้องกับการสอบเทียบเกณฑ์ PROP-FLOOD-06

1. ให้ตัวอย่างจริงของหลักการ **"เลือก design/reference event จากค่าที่รุนแรงสุดในรอบยาว (30 ปี)"** —
   ใช้สนับสนุนวิธีคิดในการเลือกค่า `F_H` upper bound reference แม้ตัวเลขจริง (90-100 มม./ชม.) เป็น
   ของจันทบุรี ไม่ใช่ของสัมมากร/กทม.
2. ยืนยันด้วยกรณีศึกษาแยกจาก กทม. ว่า **"พื้นที่แอ่ง+ไม่มีการซึมน้ำ" เป็นตัวเร่งการท่วมขังที่ระบบระบาย
   ปกติรับมือไม่ไหว** แม้ปริมาณฝนรวมทั้งปีไม่ผิดปกติ — corroborate หลักการว่า S_H/T_act ต้องดูทั้ง
   ความเข้มฝน (มม./ชม.) และสภาพพื้นที่รองรับ (ไม่ใช่แค่ปริมาณสะสมรายวัน)

## ขอบเขต — ไม่ใช้เอกสารนี้ตรงไหน

**ห้ามอ้างค่า Manning's N (Table 1) เป็นค่า `c_U` (runoff coefficient) ของ PROP-FLOOD-06** — คนละ
นิยามทางคณิตศาสตร์ (ดู Findings ข้อ 3) ห้ามอ้างตัวเลข 90-100 มม./ชม. หรือ 0.82 เมตรเป็นตัวเลขของ
สัมมากร/กทม. — เป็นของจันทบุรีเท่านั้น ใช้เป็นบริบทเชิงกลไก/วิธีการเท่านั้น
