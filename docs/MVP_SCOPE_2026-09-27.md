# ขอบเขต MVP ของการพยากรณ์ — สัมมากร + กทม. (2026-09-27)

**คำตัดสินฟาวน์เดอร์ (คำต่อคำ)**:
- "เขียนโน้ตด้วยว่า เอาสัมมากรและ กทม. เป็นตัววัดพยากรณ์ MVP ก่อน ที่เหลือค่อยว่ากัน เป็นเวอร์ชันถัดไป"
- "เพื่อไม่ให้ขยาย เอาแค่ที่ กทม ก่อน แล้วอันอื่นค่อยๆ ขยับไปเทส"

## 1. MVP วัดผลที่ไหน

การพยากรณ์ MVP วัดผล **เฉพาะ** สองที่:
1. **สัมมากร** — ระดับโหนด/จุด (หน่วย `sammakorn` ที่ขึ้นทะเบียนไว้แล้ว, ถนนบางกะปิ, สายคลองแสนแสบ–ประเวศ–ลาดพร้าว–บ้านม้า)
2. **กทม.** — ระดับเขต (50 เขต) และพื้นที่ปิดล้อมย่อย 38 แห่งของ สนน. (ฝั่งตะวันออกก่อน)

## 2. ทำไมเริ่มที่ กทม. (INSTINCT, อิงของที่มีจริงในคลัง — MEASURED ตามไฟล์ที่อ้าง)

กทม. คือที่ที่ข้อมูลของเราลึกที่สุด: ตารางแผน สนน. 2569 (`docs/knowledge/bma_plan2569_*.yaml`), สถานีเครือข่ายอัตโนมัติจากแผน 1,012 สถานีพร้อมพิกัด
(`docs/knowledge/bma_plan2569_stations.yaml` 1,012 แถว — MEASURED; เล่มระบุ 1,015), พื้นที่ปิดล้อมย่อย 38 แห่งพร้อมพื้นที่, telemetry ถนนน้ำท่วม 243 สถานี
(`thaiwater_flood_road`), บัญชีเหตุการณ์ (`sources/urban_flood_event_ledger.yaml`), และหน่วยสัมมากรที่ขึ้นทะเบียนไว้ใน PROP-FLOOD-06.

## 3. อะไรนับเป็น MVP

- ระดับ zoom 0–3 สำหรับ กทม. (คัดกรอง → เขต/พื้นที่ปิดล้อม → โหนดคลอง → จุด)
- ร่าง PROP-FLOOD-10 (Toledo worktree, NEW DERIVATION / PROPOSAL — not yet in Toledo)
- การทดสอบย้อนหลังด้วยข้อมูลจริง: `docs/experiments/2026-09-27-zoom-forecast-real-backtest.md`
- ข้อความบนหน้าเว็บที่เกี่ยวกับการพยากรณ์ — เฉพาะหน่วยใน กทม. และต้องผ่านสมการที่ขึ้นทะเบียนแล้วเท่านั้น
