# 🌧️ FloodConnect Skill

### ทำให้ AI ของคุณเข้าใจน้ำท่วมไทย

**บ้านฉันเสี่ยงน้ำท่วมไหม? • ตอนนี้ควรดูข้อมูลอะไร? • ต้องเตรียมตัวอย่างไร?**

FloodConnect ช่วยให้ผู้ช่วย AI **รวบรวมข้อมูลน้ำ ฝน และลุ่มน้ำจากแหล่งสาธารณะ**  
เพื่ออธิบายสถานการณ์พร้อมแหล่งที่มา ชี้สิ่งที่ยังไม่ทราบ และเสนอทางเลือกในการเตรียมตัว (`VERIFIED`: [วิธีคิดที่เผยแพร่แล้ว](skills/floodconnect-method/SKILL.md); `RELAYED`: ข้อมูลหน่วยงาน)

**ฟรีสำหรับโค้ดและคู่มือ • Open Source • รองรับข้อมูลระดับสถานี/ลุ่มน้ำทั่วประเทศไทยเมื่อมีข้อมูลเพียงพอ**  
`VERIFIED` [โค้ดและสัญญาอนุญาต](LICENSE) · [ความสามารถปัจจุบัน](system_capabilities.json) / `RELAYED` ข้อมูลสถานีจากหน่วยงานต้นทาง ([ทะเบียนข้อมูล](sources/registry.yaml))

> [!IMPORTANT]
> **FloodConnect เป็นวิธีคิดและชุดเครื่องมือช่วยอ่านสถานการณ์ ไม่ใช่คำทำนายว่าจะท่วมแน่นอนหรือไม่ท่วมแน่นอน** (`VERIFIED`: [ขอบเขตระบบ](system_capabilities.json))  
> ระบบไม่ได้พยากรณ์ความลึกน้ำท่วม ไม่รับรองความปลอดภัย และไม่ใช่ระบบแจ้งเตือนภัยทางการ ข้อมูลที่เก่า ขาดหาย หรือขัดแย้งกันต้องแสดงตามจริง (`VERIFIED`: [กติกา AI](AI.md))

## 👀 เข้าใจใน 4 วินาที

| สิ่งที่อยากรู้ | FloodConnect ช่วยอย่างไร | หลักฐาน |
|---|---|---|
| 🌧️ **ฝนจะเป็นอย่างไร?** | ดูพยากรณ์ **ฝน** จากหลายแบบจำลอง โดยแยกที่มาและเวลาออกผล | `VERIFIED` ฟังก์ชัน / `RELAYED` พยากรณ์ |
| 💧 **น้ำแถวบ้านเป็นอย่างไร?** | อ่านค่าจากสถานี/ลุ่มน้ำที่เกี่ยวข้อง พร้อมเวลาและสถานะความสดของข้อมูล | `VERIFIED` ฟังก์ชัน / `RELAYED` สถานี |
| 🧭 **ต้องเตรียมตัวอย่างไร?** | ช่วย AI อธิบายเหตุผล ข้อมูลที่ยังขาด และทางเลือกในการเตรียมตัว | `VERIFIED` คู่มือวิธีคิด |
| 🔍 **เชื่อถือได้แค่ไหน?** | แสดงแหล่งข้อมูล แท็กหลักฐาน และสิ่งที่ยังตอบไม่ได้อย่างตรงไปตรงมา | `VERIFIED` รูปแบบผลลัพธ์ |

**คนทั่วไปใช้ถามเรื่องน้ำใกล้ตัวได้ แต่การได้คำตอบที่รันผ่าน FloodConnect จริงขึ้นอยู่กับความสามารถและการติดตั้งของ AI ที่ใช้อยู่** (`VERIFIED`: [ระดับ AI](docs/AI_TIERS.md)) ดู [ระดับความสามารถของ AI](docs/AI_TIERS.md) และ [ขอบเขตพื้นที่](#coverage)

<a id="quick-start"></a>
## 🚀 เริ่มใช้งาน | Start here

### ทางเลือก A — ให้ AI ของคุณอ่าน “วิธีคิด” ก่อน (เหมาะกับผู้เริ่มต้น)

1. เปิดไฟล์ [`skills/floodconnect-method/SKILL.md`](skills/floodconnect-method/SKILL.md) ซึ่งเป็นคู่มือวิธีวิเคราะห์สำหรับ AI (`VERIFIED`: มีไฟล์จริง)
2. ถ้า AI รองรับการติดตั้ง Skill ให้ใช้ **ทั้งโฟลเดอร์** [`skills/floodconnect-method/`](skills/floodconnect-method/) ตามวิธีของ AI นั้น; หากรองรับเพียงข้อความหรือเอกสาร ให้อ่านคู่มือและไฟล์ตัวอย่างที่เกี่ยวข้อง
3. ให้ AI อ่าน [`llms.txt`](llms.txt) ก่อนตอบคำถามเรื่อง FloodConnect และเริ่มจากคำถามเกี่ยวกับพื้นที่ของคุณ

> [!NOTE]
> **อ่าน SKILL.md หรือเซฟภาพประชาสัมพันธ์ ไม่ได้แปลว่า AI เรียกใช้โปรแกรม FloodConnect แล้ว** (`VERIFIED`: [ความสามารถ AI](docs/AI_TIERS.md)) หาก AI เข้าถึงเว็บ/ข้อมูลจริงไม่ได้ ให้ขอข้อมูลล่าสุดจากหน่วยงานทางการแล้วส่งให้ AI วิเคราะห์พร้อมระบุที่มา การติดตั้งแบบนี้เป็นการใช้ **วิธีคิด** ไม่ใช่การเปิดบริการข้อมูลสดจากทีมงาน

### ทางเลือก B — ติดตั้งเครื่องมือจริง (สำหรับคอมพิวเตอร์/AI ที่ใช้คำสั่งได้)

ตัวอย่างสำหรับระบบที่มี `python3`, `git` และ shell แบบ Unix:

~~~bash
git clone https://github.com/morrocwi/floodconnect.git
cd floodconnect
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[mcp]'
floodconnect answer --at sammakorn --json
~~~

คำสั่ง `answer` **พยายามดึงข้อมูลใหม่เมื่อถูกเรียกใช้งาน** โดยค่าเริ่มต้น (`VERIFIED`: [AI.md](AI.md)); ไม่ใช่ระบบที่อัปเดตให้อัตโนมัติ หากบางแหล่งอ่านไม่ได้ ผลลัพธ์อาจเป็น `UNKNOWN`/`OPEN` ได้

เมื่อมีพิกัดเอง ให้ AI ตรวจโครงข่ายความรู้ (KG) ก่อน เช่น:

~~~bash
floodconnect locate --at "<lat>,<lon>" --json
floodconnect answer --at "<lat>,<lon>" --json
~~~

หากต้องการต่อ AI ผ่าน MCP (`VERIFIED`: มีโค้ด MCP ในรีโป) ให้ใช้ [`skills/floodconnect/SKILL.md`](skills/floodconnect/SKILL.md) และ [ตัวอย่างตั้งค่า MCP](tools/mcp/README_config_example.json); การติดตั้งแพ็กเกจ `[mcp]` เป็นส่วนที่จำเป็นสำหรับเซิร์ฟเวอร์ MCP

**เลือกเส้นทางให้ตรงกับ AI ของคุณ**

| ความสามารถที่มี | เริ่มจาก | ผลที่คาดหวัง |
|---|---|---|
| **แชท AI ที่อ่านเว็บได้** แต่รันเครื่องมือไม่ได้ | [`llms.txt`](llms.txt) + [วิธีหาสถานีจากแหล่งทางการ](docs/NEAREST_STATION_RECIPE.md) | ช่วยอ่าน/อธิบายข้อมูลทางการ โดย **ไม่อ้างว่าได้รัน FloodConnect CLI/MCP** |
| **AI ที่รับ Skill/เอกสาร** | [`skills/floodconnect-method/`](skills/floodconnect-method/) | ใช้หลักการและขั้นตอนของ FloodConnect ภายใต้เครื่องมือที่ AI นั้นเข้าถึงได้ |
| **AI บนเครื่องที่ต่อ MCP ได้** | [`skills/floodconnect/`](skills/floodconnect/) + [ตั้งค่า MCP](tools/mcp/README_config_example.json) | เรียก `floodconnect_answer` แล้วอ่านผลจริงพร้อมแท็กหลักฐาน |
| **AI/นักพัฒนาที่ใช้เทอร์มินัลได้** | [ติดตั้ง CLI](#quick-start) | รัน `floodconnect locate` / `floodconnect answer` จริงบนเครื่องตัวเอง |

**หลักสำคัญ** (`VERIFIED`: [AI.md](AI.md)): เริ่มจาก KG (`kg_anchor`) ทุกครั้ง, ตรวจวันเวลาข้อมูล และแยก **สถานะปัจจุบัน** ออกจาก **แนวโน้มฝนในอนาคต** — [วิธีปฏิบัติสำหรับ AI](AI.md)

## 💬 ลองถาม AI ของคุณ

> **“บ้านฉันอยู่ที่… ช่วยหาสถานีวัดน้ำและลุ่มน้ำที่เกี่ยวข้อง แล้วบอกด้วยว่าข้อมูลล่าสุดเมื่อไร”**

> **“ตอนนี้น้ำใกล้บ้านเป็นอย่างไร? ฝนช่วงต่อไปมีแนวโน้มอย่างไร? แยกสองเรื่องนี้ให้ชัดเจน”**

> **“หากฝนตกต่อเนื่อง ฉันควรติดตามปัจจัยอะไร และมีทางเลือกในการเตรียมตัวอย่างไรบ้าง?”**

> **“ข้อมูลจุดไหนยังไม่พอที่จะสรุป และฉันควรตรวจสอบกับหน่วยงานใด?”**

ผลลัพธ์จริงขึ้นอยู่กับ **พิกัด สิทธิ์การเข้าถึงข้อมูล เครื่องมือของ AI และความสดของแหล่งข้อมูล** (`VERIFIED`: [ข้อจำกัด](docs/AI_TIERS.md)) — ตัวอย่างรูปแบบข้อมูลเก่าที่ระบุวันชัดเจนอยู่ใน [`examples/`](examples/) และไม่ใช่ค่าน้ำปัจจุบัน

<a id="capabilities"></a>
## 🧩 ความสามารถที่มีจริง | Capability status

ใช้แท็ก **สถานะฟีเจอร์** 5 คำ เพื่อแยกสิ่งที่มีแล้วออกจากแผนงาน:

- **`RELEASED`** — มีในซอฟต์แวร์ที่เผยแพร่แล้ว
- **`LIMITED`** — ใช้ได้บางพื้นที่/บางแหล่งข้อมูล หรือยังมีข้อจำกัดด้านการตรวจวัด
- **`PLANNED`** — แนวคิดหรือแผนรุ่นต่อไป ยังไม่ใช่ความสามารถใช้งานจริง
- **`OPEN`** — ยังไม่มีหลักฐานพอให้ยืนยัน หรือมีประเด็นที่ต้องตรวจสอบต่อ
- **`NOT PROVIDED`** — ไม่ใช่บริการ/ความสามารถที่โครงการเปิดให้ใช้ในรุ่นนี้

| ความสามารถ | สถานะฟีเจอร์ | แท็กหลักฐาน¹ | ขอบเขตที่ควรเข้าใจ |
|---|---|---|---|
| อ่านสถานะน้ำจากข้อมูลสถานี/ลุ่มน้ำทั่วประเทศ | `RELEASED` · `LIMITED` | `VERIFIED` (โค้ด) / `RELAYED` (ข้อมูลต้นทาง) | เป็นระดับสถานี/ลุ่มน้ำ เมื่อมีข้อมูลสดและตรงพื้นที่ ไม่ใช่การวัดทุกหลังคาเรือน |
| รายละเอียดเฉพาะพื้นที่สัมมากรและซอยรามคำแหง 53 | `RELEASED` · `LIMITED` | `VERIFIED` (ตัวระบบ) / `RELAYED` (สถานี) | เป็น 2 พื้นที่ที่มีความละเอียดระดับบ้าน/โหนด; ความครบถ้วนขึ้นกับแหล่งข้อมูล |
| โครงข่ายความรู้ (KG) และ `kg_anchor` | `RELEASED` | `VERIFIED` (ไฟล์ KG และโค้ด) | ใช้เพื่อระบุบริบทพื้นที่/ลุ่มน้ำ/สถานี ไม่ใช่ผลทำนายน้ำท่วม |
| รายงานสถานะปัจจุบันและแนวโน้มฝนแยกกัน | `RELEASED` | `VERIFIED` (โค้ด) / `RELAYED` (พยากรณ์) | ฝนเป็นข้อมูลพยากรณ์จากแบบจำลองภายนอก ไม่ใช่พยากรณ์ระดับน้ำหรือความลึกน้ำท่วม |
| อ่านข้อมูลกล้องสาธารณะที่แค็ตตาล็อกมี | `RELEASED` · `LIMITED` | `VERIFIED` (โค้ด) / `RELAYED` (แค็ตตาล็อก) | เป็นหลักฐานให้ผู้ใช้ตรวจด้วยสายตา ไม่ใช้ตัดสินความปลอดภัย |
| วิธีใช้งานผ่าน `SKILL.md` / CLI / MCP | `RELEASED` · `LIMITED` | `VERIFIED` (ไฟล์/การทดสอบ) | แต่ละ AI รองรับไม่เท่ากัน; บางแบบต้องติดตั้งบนคอมพิวเตอร์ |
| พยากรณ์ความลึกน้ำท่วมเฉพาะบ้าน | `NOT PROVIDED` | `OPEN` (ไม่มีหลักฐานรองรับผลพยากรณ์) | ยังไม่มีหลักฐานวัดผลที่รองรับให้กล่าวอ้างเป็นความสามารถที่ใช้งานได้ |
| โมเดล Water-Debt / One-Decision แบบเต็ม | `PLANNED` | `OPEN` (ยังไม่อยู่ในเส้นทางผลิตจริง) | อยู่ในแผน/งานวิจัย ไม่ใช่ผลลัพธ์ผลิตจริงในรุ่นนี้ |
| เว็บ/API โฮสต์กลางสำหรับข้อมูลสดและแจ้งเตือนอัตโนมัติ | `NOT PROVIDED` | `VERIFIED` (สถาปัตยกรรมรีโป) | **ไม่มีบริการลักษณะนี้ในโครงการปัจจุบัน**; ผู้ใช้งานเป็นฝ่ายเรียกเครื่องมือเอง |

¹ แท็กหลักฐานข้างต้นอธิบาย **หลักฐานที่รองรับแต่ละข้ออ้าง** ไม่ใช่การยืนยันค่าระดับน้ำใด ๆ ณ เวลานี้: `VERIFIED` คือการตรวจความสามารถจากไฟล์/โค้ดหรือการทดสอบในรีโป, `RELAYED` คือข้อมูลของหน่วยงานต้นทาง, และ `OPEN` คือข้ออ้างที่ยังไม่มีผลยืนยัน ดู [คำจำกัดความแท็ก](#evidence-tags)

ตรวจข้อเท็จจริงเชิงเครื่องจาก [`system_capabilities.json`](system_capabilities.json), นิยามตัวชี้วัดจาก [`docs/INDICATORS.md`](docs/INDICATORS.md), ผลทดลองและข้อจำกัดจาก [`docs/EVIDENCE.md`](docs/EVIDENCE.md) และประวัติรุ่นจาก [`CHANGELOG.md`](CHANGELOG.md)

### 3. Out of scope / ขอบเขตของโครงการ (README §3)

**นอกขอบเขตรุ่นนี้:** การรับรองว่าจะท่วมหรือไม่ท่วมรายบ้าน, การพยากรณ์ความลึกน้ำ, และบริการข้อมูลสดแบบโฮสต์กลาง (ดู [ข้อจำกัด](#limitations) และ [หลักฐาน](docs/EVIDENCE.md))

**ทั่วประเทศไทย — ความละเอียดระดับสถานี/ลุ่มน้ำ** (`VERIFIED`: [ความสามารถปัจจุบัน](system_capabilities.json) / `RELAYED`: ข้อมูลสถานี): เครื่องมือรับพิกัดและพยายามเลือกข้อมูลสถานีที่มีความสัมพันธ์ตามกฎที่ระบุไว้ในโครงการ พร้อมตรวจเวลาและแสดงระดับความไม่แน่นอน **ไม่ได้หมายถึงทุกตำบลมีเซนเซอร์หรือข้อมูลครบ** (`RELEASED` / `LIMITED`)

**กรุงเทพฯ — ความละเอียดมากขึ้นเฉพาะพื้นที่ต้นแบบ** (`VERIFIED`: [ความครอบคลุมที่เผยแพร่](system_capabilities.json)): หมู่บ้านสัมมากรและซอยรามคำแหง 53 (`RELEASED` / `LIMITED`) ไม่ได้แปลว่าครอบคลุมรายละเอียดของทุกชุมชนในกรุงเทพฯ

**พิกัดและสถานที่ใกล้ตัว** (`VERIFIED`: [แนวทางจุดพิกัด](docs/NEAREST_STATION_RECIPE.md)): AI ของผู้ใช้หรือเครื่องมือแผนที่ของผู้ใช้ต้องช่วยหาพิกัดเอง FloodConnect ไม่ได้โฮสต์ฐานข้อมูลสถานที่/ที่พักพิง/เส้นทางสำหรับค้นหาใกล้ตัว ดู [วิธีเลือกสถานี](docs/NEAREST_STATION_RECIPE.md) และ [คู่มือ KG](docs/KG_QUERY.md)

<a id="limitations"></a>
## 🛟 สิ่งที่ต้องรู้ก่อนใช้ | Safety & honesty

> [!WARNING]
> **สถานะ `UNKNOWN` หรือ `OPEN` ไม่เท่ากับ “ปลอดภัย”** (`VERIFIED`: [กติกาหลักฐาน](AI.md)) และสี/ระดับสถานีไม่ใช่คำรับรองว่าถนน บ้าน หรือเส้นทางจะผ่านได้

- **ข้อมูลปัจจุบัน ≠ การพยากรณ์** (`VERIFIED`: [AI.md](AI.md)): รายงานค่าน้ำจากสถานีคือสิ่งที่สังเกตได้; พยากรณ์ที่เชื่อมอยู่เป็น **ฝน** จากแบบจำลอง ไม่ใช่ความลึกน้ำท่วมในอนาคต
- **ไม่โฮสต์ข้อมูลสด** (`VERIFIED`: [ข้อเท็จจริงด้านโฮสต์](system_capabilities.json)): มีหน้าอธิบายโครงการแบบ static เท่านั้น; ไม่มี API สดกลางและไม่มีการอัปเดตตามเวลาตายตัว ผลสดต้องมาจากการเรียกใช้บนเครื่อง/เครือข่ายของผู้ใช้
- **ข้อมูลขาด/เก่า/ขัดแย้ง** (`VERIFIED`: [AI.md](AI.md)): แสดงข้อจำกัดแทนการแต่งตัวเลขหรือเลือกข้อมูลที่ขัดกันเพียงด้านเดียว
- **ไม่ได้พิสูจน์ความแม่นยำระดับบ้านทั่วประเทศ** (`OPEN`: [หลักฐานปัจจุบัน](docs/EVIDENCE.md)): อ่าน [หลักฐานการประเมินและผลทดสอบ](docs/EVIDENCE.md) ก่อนนำไปอ้างในเชิงประสิทธิภาพ
- **เมื่อเกิดเหตุจริง** (`RELAYED`: ช่องทางหน่วยงาน): ใช้ประกาศของหน่วยงานรับผิดชอบเป็นหลัก; ช่องทางติดต่อที่เกี่ยวข้อง ได้แก่ **1784** (ปภ.), **1555** (กทม.), **1669** (เจ็บป่วยฉุกเฉิน), **1130** (ไฟฟ้ากรุงเทพฯและพื้นที่บริการ) และ **Traffy Fondue** สำหรับการแจ้งปัญหา

คำตอบทุกครั้งควรมี **แหล่งข้อมูล + เวลาที่ข้อมูลถูกตรวจวัด/ประกาศ + แท็กหลักฐาน + `kg_anchor`** ตามข้อกำหนดของ [`AI.md`](AI.md)

### 6. Test it with your AI / ตั้งค่าและทดลอง MCP (README §6)

หลังติดตั้ง `pip install -e '.[mcp]'` ให้ AI client ที่รองรับ MCP ตั้งค่า server บนเครื่องผู้ใช้ ตาม [ตัวอย่างไฟล์ config](tools/mcp/README_config_example.json) จากนั้นอ่าน [`AI.md`](AI.md) และทดสอบให้ AI เรียก `floodconnect_answer` จริง โดยแยก `state` กับ `hazard` ตามแหล่งและเวลา หากไม่มีข้อมูลใหม่ต้องแสดง `UNKNOWN`/`OPEN` ไม่สรุปความปลอดภัย

~~~bash
# ดูคำสั่งหลัก
floodconnect answer --at sammakorn --json
floodconnect forecast --at sammakorn
floodconnect connectors --live

# โหมดที่ไม่ดึงข้อมูลใหม่ (ใช้ฐานข้อมูลในเครื่องเท่านั้น)
floodconnect answer --at sammakorn --offline

# ทดสอบโปรเจกต์
python3 -m pytest tests/ -q
~~~

**ขอบเขตระบบ** (`VERIFIED`: [system_capabilities.json](system_capabilities.json)): `kb.py` / CLI / MCP ทำงานบนเครื่องของผู้ใช้; ไม่มี backend กลางจากโครงการ ข้อมูลตัวอย่างใน Git ถูกระบุวันและไม่ใช่ค่าล่าสุด ส่วน `site/landing/` เป็นหน้าอธิบายแบบ static เท่านั้น

งานที่แตะสมการ แหล่งข้อมูล หรือ KG ต้องปฏิบัติตาม [`AGENTS.md`](AGENTS.md) และ [`CONTRIBUTING.md`](CONTRIBUTING.md) ไม่ใช้ผลทดลองเป็นผลผลิตจริง และต้องมีผู้ตรวจแยกจากผู้เขียนก่อนเผยแพร่

## 7. แหล่งข้อมูลและสิทธิใช้งาน | Data sources & licence (README §7)

FloodConnect ช่วยอ่านข้อมูล (`RELAYED`: ข้อมูลต้นทาง / `VERIFIED`: [ทะเบียนการเชื่อมต่อ](sources/registry.yaml)) จาก **หน่วยงานน้ำของไทย** (เช่น กทม., กรมชลประทาน และ สสน.) ประกอบกับ **แหล่งพยากรณ์และข้อมูลสาธารณะภายนอก** โดยแต่ละแหล่งมีเงื่อนไขการเข้าถึง ความสด และสิทธิการใช้ข้อมูลต่างกัน โปรดตรวจแหล่งต้นทางและ [ทะเบียนแหล่งข้อมูล](sources/registry.yaml) เป็นรายรายการ

**สัญญาอนุญาตไม่เหมือนกันทั้งระบบ** (`VERIFIED`: [LICENSE](LICENSE))

- **โค้ด** — [MIT](LICENSE) (`RELEASED`)
- **เอกสาร/ข้อความ** — [CC BY 4.0](LICENSE)
- **ข้อมูลของหน่วยงานหรือบุคคลที่สาม** — เป็นไปตามสิทธิของเจ้าของข้อมูลแต่ละแหล่ง; หลายรายการยังมีสถานะใบอนุญาตที่ต้องตรวจสอบ (`OPEN`) จึงต้องพิจารณาก่อนนำข้อมูลไปเผยแพร่ซ้ำหรือใช้เชิงพาณิชย์
