# น้ำเหนือที่ส่งผลต่อคลองหมู่บ้านสัมมากร (เขตสะพานสูง) — สรุปเพื่อเฝ้าระวัง

บริบท: สัมมากร (13.758235N, 100.676084E) พื้นดิน 0–0.5 ม.รทก. อยู่ด้านในแนวคันกั้นน้ำพระราชดำริฝั่งตะวันออก ติดคลองบ้านม้า (→คลองแสนแสบ 1.3 กม.) และคลองวังใหญ่บน/วังใหญ่→ทับช้าง/หัวหมาก→ประเวศบุรีรมย์

## 1. แผนที่คำ: น้ำเหนือมาถึงคลองสัมมากรได้กี่ทาง

**(ก) ทางตรงที่สุด (CONFIRMED)** — คลองแสนแสบ/ประเวศบุรีรมย์เป็นคลองสายเดียวต่อเนื่องจากมีนบุรี–คันนายาว–คลองสามวา–หนองจอก–ลาดกระบัง ไหลผ่านสะพานสูง/ประเวศ/สวนหลวงเอง ก่อนออกที่สถานีสูบน้ำพระโขนงลงเจ้าพระยา ฝนสะสมต้นน้ำโซนนี้ (25 ก.ย. 69: มีนบุรี 123.5 มม., คันนายาว/สายไหม 133 มม.) ไหลถึงระดับน้ำหน้าบ้านโดยตรงในคลองเส้นเดียวกัน — ยืนยันจากสถานี BMA จริง 10 สถานี (สอดคล้องกับเหตุการณ์จริง 25 ก.ย. ที่น้ำแสนแสบขึ้นสูงจนปิดจุดกลับรถ "แยกบ้านม้า" เอง)

**(ข) ทางอ้อม-มีเงื่อนไข (เส้นทางมีจริง CONFIRMED, ทิศทางสุดท้าย OPEN)** — แม่น้ำป่าสัก (เหนือเขื่อนพระรามหก) → คลองระพีพัฒน์ → คลอง 13/14 → คลองหกวาสายล่าง → ปลายคลอง 13 (หนองจอก) → ลงคลองแสนแสบ เอกสารกรมชลประทาน (water.rid.go.th) ยืนยันเส้นทางนี้ตรงคำต่อคำ **แต่ระบุชัดว่าจุดประสงค์หลักคือผลักดันน้ำไปทางนครนายก/บางปะกง เหลือเพียง "ส่วนที่เหลือ" เท่านั้นที่ลงแสนแสบที่หนองจอก** ซึ่งอยู่ทางตะวันออกของสัมมากร — ยังไม่มีแหล่งใดยืนยันว่าน้ำส่วนนั้นไหลย้อนมาถึงช่วงสัมมากรจริง หรือถูกกัก/ไหลต่อทางตะวันออก (**ช่องว่างสำคัญที่สุดที่ควรตามต่อ**)

**(ค) ทางอ้อมระดับนโยบาย** — เจ้าพระยาสายหลัก (นครสวรรค์, ชัยนาท, อยุธยา) ไม่ไหลเข้าแสนแสบ/ประเวศโดยตรง แต่เอกสาร RID ระบุตรงว่ากรมชลฯ **จงใจจำกัด** น้ำที่ปล่อยผ่านปตร.จุฬาลงกรณ์เข้าคลองรังสิต เพราะจะเพิ่มระดับน้ำ "ด้านนอกคัน" (ฝั่งที่สัมมากรอยู่) ระดับเจ้าพระยา/ป่าสักจึงเป็นแรงกดดันเชิงนโยบายต่อการเปิด-ปิดประตูน้ำ มากกว่าน้ำที่ไหลถึงบ้านโดยตรง

## 2. พื้นที่/จังหวัดที่ต้องรู้ (เรียงความสำคัญ)

1. **กทม. ฝั่งตะวันออก** (มีนบุรี, คันนายาว, คลองสามวา, หนองจอก, ลาดกระบัง, ประเวศ) — ต้นน้ำโดยตรงของแสนแสบ/ประเวศ ฝนสะสมที่นี่คือสัญญาณตรงที่สุด (CONFIRMED)
2. **ปทุมธานี** (รังสิต, คลองหลวง, ลำลูกกา, หนองเสือ) — ป้อนคลอง 13/14 ที่ปลายทางลงแสนแสบที่หนองจอก ปริมาณถูกจำกัดโดยนโยบาย ทิศทางสุดท้าย OPEN (เส้นทาง CONFIRMED, ผลถึงสัมมากร PLAUSIBLE)
3. **ลพบุรี/สระบุรี** (เขื่อนป่าสักชลสิทธิ์, ปตร.พระนารายณ์/พระศรีเสาวภาค) — ต้นทางน้ำที่ตัดสินใจปล่อยเข้าคลองระพีพัฒน์ (โครงสร้าง PLAUSIBLE, พิกัดสถานี OPEN)
4. **นครสวรรค์/ชัยนาท/อ่างทอง/อยุธยา** (เจ้าพระยาสายหลัก) — สัญญาณนโยบายภาพรวมเท่านั้น ไม่ใช่น้ำที่ไหลเข้าคลองโดยตรง (INSTINCT)
5. **ฉะเชิงเทรา (บางปะกง)** — ปลายทางรับน้ำจากคลอง13/14/ประเวศ ผลกระทบย้อนกลับ (backwater) ยังไม่มีแหล่งวิเคราะห์ (OPEN)

## 4. สัญญาณเตือนล่วงหน้าที่เอกสารทางการระบุจริง

- เอกสาร RID (water.rid.go.th/flood/flood/report_king.htm, ยืนยันโดยผู้ตรวจอิสระว่าอ่านตรงจริง) ระบุ**กลไก**ควบคุม (จำกัดน้ำที่ปตร.จุฬาลงกรณ์เข้ารังสิต) แต่**ไม่ได้ระบุตัวเลข lag เวลาหรือ threshold ที่จับต้องได้**สำหรับคลองแสนแสบ/ประเวศ — ไม่มีสัญญาณเชิงตัวเลข verified ให้ใช้ ณ ขณะนี้
- สทนช. ประกาศฉบับที่ 5/2569 (RELAYED เท่านั้น ยังไม่อ่านต้นฉบับ onwr.go.th): อ้างเจ้าพระยาท้ายเขื่อนสูงขึ้น 0.75–1.25 ม. กระทบพื้นที่นอกคันชัยนาท-สิงห์บุรี-อ่างทอง-อยุธยา-ปทุมธานี — ใช้เป็นแนวโน้มเท่านั้น ยังไม่ verified
- ปริมาณสูบพระโขนง/บางอ้อ เป็น "ผล" ไม่ใช่ "สัญญาณล่วงหน้า" ระดับน้ำ Tier ต้นน้ำ (มีนบุรี/ลาดกระบัง) น่าจะขึ้นก่อนสัมมากรตามระยะทาง 10–20 กม. และความลาดเทต่ำมาก (1:25,000–1:30,000 ตามเอกสาร RID) → lag น่าจะเป็นหลักวัน (INSTINCT, ไม่มีเอกสารระบุตัวเลขวัน/ชั่วโมงตรงๆ)

## 5. สิ่งที่ยังไม่รู้ (OPEN)

- **ทิศทางน้ำจากปลายคลอง 13 (หนองจอก) หลังลงแสนแสบ** ไหลย้อนตะวันตกถึงสัมมากรจริงหรือถูกกัก/ไหลต่อตะวันออก — คำถามสำคัญที่สุด → ควรสอบถามสำนักการระบายน้ำ กทม. (DDS) โดยตรง หรือขอ hydraulic model ของระบบแสนแสบ-ประเวศทั้งเส้น
- **พิกัด/รหัสจริงของ C.29A (บางไทร)** และประตู/สถานีสูบต้นทางฝั่งรังสิต (ปตร.พระนารายณ์, พระศรีเสาวภาค, พระธรรมราชา, จุฬาลงกรณ์) — ควรตรวจ nationalthaiwater.onwr.go.th หรือขอจาก RID โดยตรง
- **ระบบระบายน้ำสนามบินสุวรรณภูมิ** ซึ่งอยู่ระหว่างลาดกระบังกับบางปะกง — ยังไม่มีแหล่งใดตรวจในเซสชันนี้ ควรหาเอกสาร ทอท./RID
- **รายงานถอดบทเรียนน้ำท่วมปี 2554 ฝั่งตะวันออก กทม.** — ยังไม่พบ/อ่านเลย (มีแต่เอกสาร RID ปี 2545) → ควรหาใน dds.bangkok.go.th หรือรายงานมหาวิทยาลัย
- **ผลกระทบย้อนกลับ (backwater) จากบางปะกง** ต่อสถานีสูบฝั่งตะวันออก (เสาวภาผ่องศรี ฯลฯ) — ยังไม่มีการวิเคราะห์
- **เกณฑ์/threshold ตัวเลขจริงจาก สทนช./thaiwater สำหรับคลองแสนแสบ** — ยังไม่พบ dashboard พยากรณ์ทางการที่ตรวจสอบแล้ว
- **สถานีสูบ/ปตร. ริมบางปะกงและชายทะเล 8 แห่ง** ที่เอกสาร RID เอ่ยชื่อ (เสาวภาผ่องศรี, สมบูรณ์, บางขนาก, ท่าไข่, ชลหารพิจิตร, คลองด่าน 2, เจริญราษฎร์, บางปลา-บางปลาร้า) — ชื่อยืนยันว่ามีจริง แต่พิกัด/ค่าปัจจุบัน OPEN
