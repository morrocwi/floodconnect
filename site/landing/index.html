The pitch / แนวคิดโดยสรุป

EN — FloodConnect brings together Thailand's scattered government open flood data, designed around our own Water-Debt decision model (v0.2+; v0.1.x answers from fixed, tested station-level rules), to answer one question honestly: at this point, right now, what should happen next? It reads the flood/canal/pump situation and hands your own AI assistant a typed, source-tagged answer — never a flood-depth prediction, never a safety certification.

TH — FloodConnect รวม open data ของรัฐไทยที่กระจัดกระจายอยู่ ออกแบบรอบโมเดลหนี้น้ำ (Water-Debt) ของเราเอง (v0.2+; v0.1.x ตอบด้วยกฎระดับสถานีที่ตายตัวและผ่านการทดสอบแล้ว) เพื่อตอบคำถามเดียวอย่างซื่อตรง: "ที่จุดนี้ ตอนนี้ ควรทำอะไรต่อ" ระบบอ่านสถานการณ์น้ำ/คลอง/ปั๊ม แล้วส่งคำตอบที่มีโครงสร้างชัดเจนพร้อมป้ายแหล่งที่มาให้ผู้ช่วย AI ของคุณ — ไม่ใช่การพยากรณ์ความลึกน้ำท่วม และไม่ใช่การยืนยันความปลอดภัย

What it is / what it is not

It is

  • A typed knowledge graph of Bangkok's river and canal network, authority/ownership, resources and a community self-help path, for two pilot areas (Sammakorn, Ram 53).
  • A small compute layer (CLI + MCP) that turns that graph plus fresh public readings into one source-tagged, age-tagged answer.
  • Self-installed and self-run: you clone it, you run it, it computes on your machine using your own network and keys.
  • Free and open source.

It is not

  • Not a hosted service — there is no server anywhere answering requests for you; nothing is live on this web page.
  • Not an official warning system — official agency notices always take precedence.
  • Not a flood-depth or water-level forecast at your address. It forecasts rain per model (relayed, not averaged); a water-debt-based outlook is planned (v0.2+) and not shipped yet.
  • Not a safety certification — "UNKNOWN" is never the same as "safe".
  • Not nationwide yet — detailed coverage today is Sammakorn and Ram 53, Bangkok only; other points get rain forecast and nearby cameras only, and their current state is usually UNKNOWN. Nationwide coverage is planned (v0.2+).

Install

git clone https://github.com/morrocwi/floodconnect
cd floodconnect
python3 -m venv .venv && . .venv/bin/activate
pip install -e '.[mcp]'
floodconnect answer --at sammakorn

Full install, CLI reference, and MCP client config are in the repository README. คำสั่งติดตั้งแบบเต็ม การใช้ CLI และการตั้งค่า MCP อยู่ใน README ของ repository

How your home AI uses it

FloodConnect's north star is the AI that already sits in your home — your own Claude, ChatGPT, or other assistant — reading the situation in one cheap call and telling you directly, in whatever language you speak.

เป้าหมายหลักของ FloodConnect คือ AI ที่อยู่ในบ้านคุณอยู่แล้ว ไม่ว่าจะเป็น Claude, ChatGPT หรือตัวอื่น อ่านสถานการณ์ด้วยการเรียกครั้งเดียวที่ราคาถูก แล้วบอกคุณตรงๆ ด้วยภาษาที่คุณใช้

  1. You (or your AI, on your machine) run floodconnect answer --at sammakorn, or connect the bundled MCP server to a desktop AI client (Claude Desktop/Code and others that support MCP).
  2. FloodConnect returns one structured answer: current state, forward hazard, who is accountable, 1–3 next actions — each value carrying its source and age.
  3. Your AI reads that structured answer and explains it to you in plain language — FloodConnect does not pre-translate or lock the wording; that is the AI's job.
  4. If data is missing or stale, the answer says UNKNOWN and tells you to refresh — it never guesses "safe" from silence.

Works with ChatGPT, Claude and other AI assistants without building a new AI — it is a tool an existing AI calls, via its own MCP client or the command line. ใช้ได้กับ ChatGPT, Claude และ AI อื่นๆ โดยไม่ต้องสร้าง AI ใหม่ เป็นเครื่องมือที่ AI ที่มีอยู่แล้วเรียกใช้ ผ่าน MCP client ของมันเองหรือ command line

Roadmap, briefly

v0.1.0 ships the knowledge graph, the readout layer and the self-install CLI/MCP for Sammakorn and Ram 53. Planned next (v0.2 and later, not yet shipped): a water-debt model as the decision core, a typed one-decision output with confidence, four-driver readings, nationwide points, and formal registration of the underlying equations. Full detail: see ROADMAP.md and the AI handoff doc in the repository.

v0.1.0 มีกราฟความรู้ ชั้นอ่านค่า และ CLI/MCP สำหรับติดตั้งเอง ครอบคลุมสัมมากรและซอยรามคำแหง 53 แผนถัดไป (v0.2 เป็นต้นไป ยังไม่เปิดใช้งาน) ได้แก่ โมเดลหนี้น้ำเป็นแกนการตัดสินใจ คำตอบแบบ one-decision พร้อมค่าความมั่นใจ ข้อมูล 4 ปัจจัยหลัก จุดครอบคลุมทั่วประเทศ และการลงทะเบียนสมการอย่างเป็นทางการ
